# 2026-04-04 Intro Guide Wording Adjustment

## Scope

- `src/App.vue` の intro-guide 注記文言
- `README.md`
- `docs/manual.md`

## Problem

- 「抽象時系列」という説明だけでは、初回表示の注記としては少し抽象度が高く、`1〜31` の日付ラベルを実日付と誤読する余地が残る
- README / manual でも同じ意味を説明しているため、文言の主語を `日付ラベル` に寄せた方が初見で読みやすい

## Change

- 「日付は」ではなく「日付ラベルは実際の月日ではなく」と表現し、何が抽象化されているのかを先に示す
- 意味は変えず、説明対象だけを明確化した

## Expected Effect

- 初回ユーザーが「画面上の 1〜31 表示は実カレンダーか」を早く判断しやすくなる
- PM の再確認を、より小さい論点で閉じやすくする
