# 物語イベント仕様

- 状態：Draft
- 仕様バージョン：0.1
- 実装状態：仕様策定前
- 関連プラン：[065 Story Event Graph View](../plan/backlog/065-story-event-graph-view.md)

## 目的

このディレクトリは、「物語イベント」ビューのStoryBlock、グラフ関係、時間配置、画面挙動、データ作成方法を長期参照できる仕様として管理します。

Draftの間は検討中の将来仕様であり、現在実装されている機能を示しません。
実装は仕様状態がApprovedになり、関連プランがactiveへ昇格した後に開始します。

## 文書構成

- [データモデル](data-model.md)：StorySeries、StoryBlock、StoryEdge、EvidenceLink、IDの契約を定義します。
- [グラフ意味論](graph-semantics.md)：方向、関係種別、循環、時間配置を定義します。
- [UI挙動](ui-behavior.md)：ノード、エッジ、操作、検索、共有URLを定義します。
- [データ作成](authoring.md)：StoryBlockと意味付きエッジの登録、出典対応、検証を定義します。
- [例](examples.md)：代表的なノードとエッジの例を保存します。
- [決定記録](decisions/README.md)：長期的な影響がある承認済み判断を保存します。

## 確定済みの前提

- 親愛度、イベント、サポカなどの話の1ブロックを1ノードとします。
- 無方向、片方向、双方向のエッジを扱います。
- エッジは意味、根拠、確度を持てます。
- グラフは循環と並列エッジを許容します。
- StoryBlockの本編発生時期と、StoryBlockが根拠として示す出来事の時期を区別します。
- 「物語時系列」や「学マス情報史」と同じ時間軸へ重ねません。

## 仕様確定条件

- StoryBlock、StoryEdge、EvidenceLinkの契約が確定していること。
- 時間配置と時期未確定ノードの扱いが確定していること。
- 最初に使う関係種別と方向の意味が確定していること。
- 表示、操作、URL、検証、データ作成手順が定義されていること。
- 代表データによる仕様レビューが完了していること。

## 未決定事項

- StoryBlockのシリーズ階層とID体系。
- StoryBlockの本編発生時期を判断する基準。
- 初期relationType一覧とエッジ根拠の必須条件。
- ノード配置、エッジ経路、密集表示の方式。
