# 物語イベント仕様

- 状態：Draft
- 仕様バージョン：0.1
- 実装状態：仕様策定前
- 関連プラン：[065 Story Event Graph View](../plan/backlog/065-story-event-graph-view.md)

## 目的

このディレクトリは、「物語イベント」ビューのStoryBlock、グラフ関係、物語上の前後関係、画面挙動、データ作成方法を長期参照できる仕様として管理します。

Draftの間は検討中の将来仕様であり、現在実装されている機能を示しません。
実装は仕様状態がApprovedになり、関連プランがactiveへ昇格した後に開始します。

- [データモデル](data-model.md)：StorySeries、StoryBlock、StoryEdge、EvidenceLink、IDの契約を定義します。
- [グラフ意味論](graph-semantics.md)：方向、関係種別、循環、物語上の流れを定義します。
- [UI挙動](ui-behavior.md)：ノード、エッジ、操作、検索、共有URLを定義します。

- [決定記録](decisions/README.md)：長期的な影響がある承認済み判断を保存します。

## 確定済みの前提

- 初期対象は、アイドルコミュ、イベントコミュ、サポートコミュ、初星コミュです。
- ゲーム内で1つのコミュとして存在する「話」を1つの正規ノードとします。
- シリーズや章はノードを分類する階層であり、それ自体をノードにはしません。
- 時期不明の話も登録し、前後関係が判明するまでは孤立ノードとします。
- 1つの話を人物別に複製せず、人物はタグやメタデータとして付与します。
- 無方向、片方向、双方向のエッジを扱います。
- エッジは意味、根拠、確度を持てます。
- グラフは循環と並列エッジを許容します。
- 「物語内時刻」は保持せず、ノードの前後関係と相対的な間隔で物語上の時系列を表します。
- ゲーム内の暦や現実世界の日時を、このビューの配置には使用しません。
- イベントの流れは上から下へ表示します。
- 「物語時系列」や「学マス情報史」と同じ時間軸へ重ねず、表示上は独立させます。
- 「物語時系列」と「学マス情報史」からStoryBlockを参照できる境界を設けます。

## 仕様確定条件

- StoryBlockとビュー間参照の契約が確定していること。
- 前後関係、相対間隔、孤立ノードの保存契約が確定していること。
- 実装開始に必要な最小限のStoryEdge契約が確定していること。
- 表示、操作、URL、検証、データ作成手順が定義されていること。
- 代表データによる仕様レビューが完了していること。
