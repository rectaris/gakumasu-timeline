# 物語イベント仕様

- 状態：Draft
- 仕様バージョン：0.1
- 実装状態：仕様策定前
- 関連プラン：[065 Story Event Graph View](../plan/backlog/065-story-event-graph-view.md)

## 目的

このディレクトリは、「物語イベント」ビューのStoryBlock、グラフ関係、物語上の前後関係、画面挙動、データ作成方法を長期参照できる仕様として管理します。

Draftの間は検討中の将来仕様であり、現在実装されている機能を示しません。
StoryBlock、StoryEdge、ビュー間参照、データ作成の契約がApprovedになり、関連プランがactiveへ昇格した後に実装を開始します。
レイアウトとUIの詳細は、この文書に記載する不変条件を守りながら実装時に調整します。

## 確定済みの前提

- 初期対象は、アイドルコミュ、イベントコミュ、サポートコミュ、初星コミュです。
- ゲーム内で1つのコミュとして存在する「話」を1つの正規ノードとします。
- シリーズや章はノードを分類する階層であり、それ自体をノードにはしません。
- 時期不明の話も登録し、前後関係が判明するまでは孤立ノードとします。
- 1つの話を人物別に複製せず、人物は役割付きのメタデータとして付与します。
- StorySeries、StoryBlock、StoryEdge、ビュー間参照には、名前空間接頭辞と小文字UUIDで構成する不変IDを使用します。
- StorySeriesは親参照で階層化し、StoryBlockは最も具体的なStorySeriesだけを参照します。
- StoryBlockに独立したタイトルを保存せず、表示対象のStorySeriesラベルとStoryBlockのラベルを階層順に連結して表示タイトルを生成します。
- 表示タイトルには技術的なカテゴリ名を含めず、各ラベルを1つの空白で連結します。
- 無方向、片方向、双方向のエッジを扱います。
- エッジは意味、根拠、確度を持てます。
- グラフは循環と並列エッジを許容します。
- 前後関係を表すエッジと意味的関係を表すエッジを区別します。
- 「物語内時刻」は保持せず、ノード間の単純な前後関係だけで物語上の時系列を表します。
- ノード間距離とエッジの長さには、時間的な意味を持たせません。
- ゲーム内の暦や現実世界の日時を、このビューの配置には使用しません。
- イベントの流れは上から下へ表示します。
- 「物語時系列」や「学マス情報史」と同じ時間軸へ重ねず、表示上は独立させます。
- 「物語時系列」と「学マス情報史」の参照元データから、型付き参照としてStoryBlockを参照します。

## 仕様確定条件

- StoryBlockとビュー間参照の契約が確定していること。
- 前後関係と孤立ノードの保存契約が確定していること。
- 実装開始に必要な最小限のStoryEdge契約が確定していること。
- 検証とデータ作成手順が定義されていること。
- UI実装中に調整できる事項と、変更してはならない不変条件が区別されていること。
- 代表データによる仕様レビューが完了していること。
