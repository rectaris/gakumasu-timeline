# 物語イベントのUI挙動

- 状態：Approved
- 仕様バージョン：1.0

## 画面構成

共通シェル、グラフ描画領域、系列ラベル、凡例、検索、詳細パネルの責務を定義します。

グラフ描画領域ではイベントの流れを上から下へ表示します。

ノード間距離とエッジの長さを時間差として表示しません。

ノード配置、エッジ経路、密集表示などの詳細は、パイロットとテスト専用fixtureを使用したUI評価で調整します。

## ノード

通常、選択、フォーカス、孤立、密集状態の表示規則を定義します。

ノードの主表示には、StorySeries階層とStoryBlockの`label`から生成した表示タイトルを使用します。

## エッジ

無方向、片方向、双方向、関係種別、選択、ラベル簡略化、交差の表示規則を定義します。

## 操作

ズーム、パン、ノード選択、エッジ選択、キーボード移動、タッチ操作を定義します。

## 検索と表示条件

カテゴリ、系列、人物の役割、relationType、方向、根拠状態の検索と絞り込みを定義します。

## 詳細

StoryBlock、StoryEdge、StoryReference、関連する物語時系列の出来事を表示する規則を定義します。

レビュー済みStoryReferenceが存在する場合だけ、物語時系列の詳細からStoryBlockへ、
StoryBlockの詳細から参照元イベントへ移動するリンクを表示します。
参照がない場合は空の欄を表示しません。

## URL

物語イベントは`mode=story-graph`で開きます。
選択状態は`node=<StoryBlock ID>`または`edge=<StoryEdge ID>`で表し、同時には使用しません。
不正または未登録のIDは選択なしとして扱います。
ブラウザの戻る・進む操作でモードと選択を復元します。

## レスポンシブ表示とアクセシビリティ

デスクトップ、狭い画面、フォーカス順、読み上げ、矢印や線種による方向表現を定義します。

## MVPで調整する事項

- 上から下への流れと分岐を両立するレイアウト方式。
- 孤立ノードを配置する領域。
- 大量ノード時の集約と仮想化。
- エッジ経路とラベル密度。
