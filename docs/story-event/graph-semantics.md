# 物語イベントのグラフ意味論

- 状態：Draft
- 仕様バージョン：0.1

## グラフ形式

無方向、片方向、双方向、並列エッジ、循環を扱う混合マルチグラフとして定義します。

## ノード

StoryBlockを1つの正規ノードとして扱い、参加キャラクターごとに複製しない規則を定義します。

物語上の位置が不明なStoryBlockも登録し、前後関係が判明するまでは孤立ノードとして扱います。

## エッジ方向

`undirected`、`forward`、`bidirectional` の意味と、接続元と接続先の読み方を定義します。

## 関係種別

必要なrelationTypeは、グラフの試作と代表例の検討を通じて決定します。

実装開始前には、接続先と方向を安全に保存できる最小限のStoryEdge契約を定義します。

## 構造エッジと意味付きエッジ

話番号から生成できる前後関係と、解釈を伴う手動登録関係を区別するかどうかを検討します。

## 物語上の流れ

物語内時刻や現実世界の日時は使用しません。

ノードの前後関係と相対的な間隔によって物語上の時系列を表し、イベントの流れは上から下へ配置します。

ノード間距離は正確な経過時間を示しません。

相対間隔の尺度とレイアウトへの変換方法は未決定です。

## 根拠と確度

意味付きエッジの根拠、出典、推定、矛盾、未解決状態を定義します。

## 未決定事項

- 最小限のStoryEdge契約と初期relationType。
- 前後関係と非時間的な意味関係を同じエッジで扱うかどうか。
- 相対間隔の尺度と保存方法。
- 自己エッジを許可する例外条件。
- 循環を利用者へ説明する方法。
