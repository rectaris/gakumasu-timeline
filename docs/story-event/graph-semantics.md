# 物語イベントのグラフ意味論

- 状態：Draft
- 仕様バージョン：0.1

## グラフ形式

無方向、片方向、双方向、並列エッジ、循環を扱う混合マルチグラフとして定義します。

## ノード

StoryBlockを1つの正規ノードとして扱い、参加キャラクターごとに複製しない規則を定義します。

## エッジ方向

`undirected`、`forward`、`bidirectional` の意味と、接続元と接続先の読み方を定義します。

## 関係種別

話数順、継続、前提、参照、並行、代替、その他の初期relationTypeを検討します。
自由記述ラベルと制御された関係種別の役割を分けます。

## 構造エッジと意味付きエッジ

話番号から生成できる順序と、解釈を伴う手動登録関係を区別します。

## 時間配置

横位置に使う本編発生時期と、エッジ方向を独立させます。
時期未確定ノード、範囲だけが判明したノード、相対順序だけが判明したノードの配置を定義します。

## 根拠と確度

意味付きエッジの根拠、出典、推定、矛盾、未解決状態を定義します。

## 未決定事項

- 初期relationTypeと方向の許可組み合わせ。
- 自己エッジを許可する例外条件。
- エッジ方向が時間を逆行する場合の表示。
- 循環を利用者へ説明する方法。
