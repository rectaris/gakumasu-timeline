# 物語イベントMVP評価

- 状態：Completed
- 評価日：2026-07-29
- 対象：未レビューパイロットとテスト専用fixture

## 評価範囲

この評価は、表示・データ契約・参照基盤を技術面から確認します。
実在コミュの内容、物語上の前後関係、公開可否は確定しません。

表示機能を試すためだけの意味的関係は、実在コミュ名を持つパイロットから除外しました。
無方向、片方向、双方向、並列エッジ、意味的循環は、非ドメイン名のテスト専用fixtureで検証します。

## 規模評価

同じ処理を繰り返せる合成データ生成器を用意し、50・100・300ノードで構造を検証しました。
各ノード数で、入力検証、全ノードの配置、エッジ数、配置順、座標の有限性を自動確認します。

2026-07-29の開発環境で7回ずつ計測した結果は次のとおりです。
実行時間は環境に依存するため、性能保証値ではありません。

| ノード | エッジ | 配置領域 | 中央値 | 最大値 |
| ---: | ---: | ---: | ---: | ---: |
| 50 | 40 | 3310 × 1020 | 0.675 ms | 6.590 ms |
| 100 | 90 | 3310 × 2000 | 0.529 ms | 1.093 ms |
| 300 | 290 | 3310 × 5920 | 0.911 ms | 4.164 ms |

現時点では、レイアウト計算を理由に専用ライブラリを追加する必要はありません。
一方、実データでの読みやすさ、密集、長い縦移動はこの合成計測だけでは判断できません。

## StoryReference

次の実装基盤を追加しました。

- 参照ID、型、表示順、StoryBlock参照先を決定的に検証する。
- 参照元の`storyReferences`を正本として、StoryBlock別の逆引き索引を生成する。
- 参照がある場合だけ、物語時系列の詳細からStoryBlockを開く。
- 逆引き参照がある場合だけ、StoryBlockの詳細から物語時系列のイベントを開く。

実在データの対応付けは追加していません。
既存`source`文字列から推測して自動登録せず、出典対応のレビュー後に追加します。

## 現時点の既知制約

- パイロットのラベル、収録対象、`sequence`は未レビューです。
- 実データ規模での密集、検索性、縦移動は未評価です。
- relationTypeの採否を判断できる実例がありません。
- グラフ専用編集画面の必要性は、データ作成を試すまで判断できません。
- 学マス情報史からのStoryReferenceは、同ビューのデータ契約確定後に接続します。

## 評価後の決定

- 未レビューパイロットはローカル開発とテストに限定します。
- 本番成果物には`published`のデータだけを含めます。
- 最初の実データ登録対象は、1つのイベントコミュとします。
- 初期エッジは`sequence/before`を中心にします。
- `semantic`のrelationTypeは、レビュー済みの実例から必要性を確認して追加します。
- 専用編集画面の要否は、最初のイベントコミュを登録した後に判断します。
- 次の主作業は「学マス情報史」の仕様策定とします。

パイロットの個別内容は承認していないため、物語イベントの本番データは空の状態から開始します。
