# 物語イベントのデータモデル

- 状態：Draft
- 仕様バージョン：0.1

## 対象

この文書は、物語イベントグラフを構成する保存データと表示時の派生データを定義します。

## エンティティ

### StorySeries

親愛度、イベントコミュ、サポカなどの系列と、その章や話の順序を表す契約を定義します。

### StoryBlock

話の1ブロックを表す安定ID、表示名、系列、話番号、参加者、本編発生時期、公開情報の契約を定義します。

### StoryEdge

接続元、接続先、方向、関係種別、表示ラベル、根拠、確度の契約を定義します。

### EvidenceLink

StoryBlockと「物語時系列」の出来事を多対多で結び、どの主張を支えるかを表す契約を定義します。

## ID

系列、ノード、エッジ、EvidenceLinkの名前空間と公開後の互換性を定義します。
日本語の表示名だけから正規IDを生成しない規則を定義します。

## 時間

本編発生時期、話数順、参照先の出来事時期、現実の公開日時を別フィールドとして扱います。

## 保存データと派生データ

手動登録する意味付きエッジと、話数順から生成する構造エッジを区別します。

## 検証

一意性、参照整合性、方向、関係種別、自己エッジ、並列エッジ、時間、不確実性の検証条件を記載します。

## 未決定事項

- EvidenceLinkを出来事側とStoryBlock側のどちらで所有するか。
- StoryBlockの公開情報を「学マス情報史」へ投影する契約。
