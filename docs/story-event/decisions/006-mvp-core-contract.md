# 006 MVPコア契約

- 状態：Accepted
- 決定日：2026-07-24

## 決定

- `sequence`は`forward`かつ`before`だけとし、配置順を決めます。
- `semantic`は配置順を変えず、初期relationTypeごとに方向を制限します。
- 自己エッジと同一論理エッジの重複を拒否し、意味が異なる並列エッジを許可します。
- 解釈を伴う関係には根拠または理由と確度を要求します。
- ビュー間参照の正式名称をStoryReferenceとし、参照元側へ複数保存できます。
- MVPは代表データで検証し、全コミュ登録や既存`source`の全件移行を含めません。
- MVPの描画は既存依存関係の範囲で実装し、評価前にグラフ専用依存を追加しません。

## 理由

物語上の前後関係と意味的な関連を混同せず、表示レイアウトを変更しても保存データの意味を維持するためです。
代表データに絞ることで、データ契約と操作感を全件移行より先に検証できます。

## 変更境界

レイアウト、エッジ経路、密集表示はMVP中に調整できます。
ID、正規ノード単位、`sequence`の意味、参照の所有元、既存relationTypeの意味を変える場合は仕様レビューと移行計画を要求します。
