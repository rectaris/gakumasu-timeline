# 初期対象、ノード単位、物語上の流れ

- 状態：Accepted
- 決定日：2026-07-19
- 対象仕様バージョン：0.1

## 背景

「物語イベント」ビューで扱うコミュの範囲、ノードの単位、時間の表現、表示方向を定める必要がありました。

## 決定

- 初期対象は、アイドルコミュ、イベントコミュ、サポートコミュ、初星コミュとします。
- ゲーム内で1つのコミュとして存在する「話」を1つの正規ノードとします。
- シリーズや章は分類階層として扱い、それ自体をノードにはしません。
- 時期不明の話も登録し、前後関係が判明するまでは孤立ノードとします。
- 同じ話を人物別に複製せず、必要な人物情報はタグやメタデータとして付与します。
- 物語内時刻と現実世界の日時は保持しません。
- 物語上の時系列はノードの前後関係と相対的な間隔で表します。
- イベントの流れは上から下へ表示します。
- 「物語時系列」と「学マス情報史」からStoryBlockを参照できるようにしますが、各ビューの表示は独立させます。

## 影響

- 日時を基準とするタイムライン描画は採用しません。
- 物語上の位置が不明なノードを排除しません。
- 画面上のピクセル距離を物語データとして直接保存するかどうかは、この決定に含めません。
- エッジの関係種別と残りの画面挙動は、代表例と試作を通じて別途決定します。
