# 前後関係、意味的エッジ、ビュー間参照

- 状態：Accepted
- 決定日：2026-07-19
- 対象仕様バージョン：0.1

## 背景

物語上の前後関係、意味的なつながり、画面上の距離を同じ性質として扱うと、意図しない配置や時間表現が発生します。

他の2ビューからStoryBlockを参照するときのデータ所有場所も定める必要があります。

## 決定

- StoryEdgeを`sequence`と`semantic`に区別します。
- `sequence`は単純な前後関係だけを表し、物語上の配置順を決めます。
- `semantic`は意味的関係を表し、物語上の配置順を変更しません。
- 物語上の順序は部分順序とし、分岐と順序不明を許容します。
- `sequence`部分グラフでは循環を禁止し、グラフ全体では循環を許容します。
- ノード間距離とエッジの長さには、時間的な意味を持たせません。
- 1つの論理エッジに`undirected`、`forward`、`bidirectional`の方向を持たせます。
- relationTypeは制御された値とし、任意の表示ラベルを併用できます。
- 解釈を伴う`semantic`エッジには、根拠または説明と確度を付与します。
- 「物語時系列」と「学マス情報史」の参照元データが、StoryBlock IDと参照種別を保持します。
- StoryBlockから参照元への逆引きは生成し、保存データへ重複させません。
- 編集用原データはカテゴリまたはシリーズ単位で管理し、表示用の索引を生成します。

## 影響

- 相対間隔や経過時間を表すフィールドは設けません。
- 初期relationType、方向の許可組み合わせ、ビューごとの参照種別は別途決定します。
- 上から下という流れ以外のレイアウトとUIの詳細は、UI実装中に調整します。
