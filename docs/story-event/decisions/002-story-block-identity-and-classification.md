# StoryBlockの同一性と分類

- 状態：Accepted
- 決定日：2026-07-19
- 対象仕様バージョン：0.1

## 背景

StoryBlockの表示名や分類が変わっても、エッジ、ビュー間参照、共有URLを維持できる同一性が必要です。

カテゴリによってシリーズ、STEP、章などの構造が異なるため、共通情報とカテゴリ固有情報の境界も定める必要があります。

## 決定

- StoryBlockとStorySeriesには、プロジェクトが発行する不変IDを使用します。
- ゲーム内ID、旧名称、現在の表示名は、不変IDとは別の外部識別子または別名として保持できます。
- 正式な表示名とカテゴリ別の構造化情報を両方保持します。
- StoryBlockの共通フィールドとカテゴリ固有の構造化情報を分けます。
- 人物参照には、`owner`、`focus`、`participant`の役割を付けられます。
- 内容が同一でも、ゲーム内で別のコミュとして管理されている場合は別のStoryBlockとします。
- 同じゲーム内コミュを別の場所から閲覧できるだけの場合は、同じStoryBlockへ対応付けます。

## 影響

- 日本語の表示名やカテゴリ階層だけから不変IDを生成しません。
- カテゴリ固有情報の具体的なフィールド名とID書式は、次のデータ契約検討で決定します。
- 表示名の変更だけでは、StoryBlockの同一性と参照先を変更しません。
