# 007 公開ライフサイクルと最初の登録対象

- 状態：Accepted
- 決定日：2026-07-29

## 決定

物語イベントのデータ状態は、`draft`、`unreviewed`、`approved`、`published`の4段階とします。

`draft`は入力中、`unreviewed`は構造検証済みで内容未確認、`approved`は出典レビュー済みで公開可能、`published`は本番成果物へ収録済みの状態です。

未レビューのデータはローカル開発とテストで使用できますが、本番成果物へ含めません。

物語イベントの実データ登録を再開するときは、1つのイベントコミュを最初から最後まで登録します。

最初の関係は`sequence/before`を中心とし、`semantic`のrelationTypeはレビュー済みの実例が繰り返し必要になった場合に追加します。

次の主作業は「学マス情報史」の仕様策定とします。

## 理由

構造上の正しさ、内容上の承認、公開判断を分けることで、表示検証用の情報が公開済みの事実として扱われることを防ぎます。

閉じたイベントコミュを最初の登録単位にすると、ノード作成、前後関係、出典レビュー、公開の手順を小さい範囲で確認できます。

## 互換性への影響

StoryBlockとStoryEdgeのID形式、既存の選択URL、グラフの意味論は変更しません。

未レビューパイロットは本番ビルドで表示されなくなります。
