# UI 挙動

## ビュー境界

`src/ApplicationRoot.vue`は、URLの`mode`から表示するページを1つだけ選びます。

- `mode`なし、`mode=narrative`、不正な値は「物語時系列」を表示します。
- `mode=story-graph`は「物語イベント」を表示します。
- `mode=realworld`はグレゴリオ暦の「学マス情報史」を表示します。
- モード変更は`history.pushState`を使用し、`popstate`で表示を復元します。
- 同じタブでモード選択欄から戻る場合は、そのモードで最後に開いていた選択や表示条件を含むURLへ戻ります。
- 各ビュー固有のクエリは別のビューへ持ち越しません。
- 開発用の`editor=worldline`は従来どおり編集画面を優先します。
- キーボードでモードを変更した場合は、新しいページの見出しへフォーカスを移します。
- アプリケーション共通の配色は`ApplicationRoot.vue`が保持し、ページを切り替えても再初期化しません。

## 水平移動 / 拡大縮小

`src/pages/NarrativeTimelinePage.vue` と `src/composables/useZoomMachine.js` では、水平方向を連続 viewport として扱います。

- `viewRange.min / max` が現在の表示範囲です
- 内部的には `horizontalCenter` と `horizontalSpan` から算出します
- `全体` は全イベントが入る全体表示に戻します
- 選択イベントが表示範囲からはみ出すと、そのイベントが収まる幅まで自動調整します

## ズーム操作 UI

- 画面下部中央の固定操作エリアとして、タイムラインを覆いすぎないコンパクトな面で表示する
- 期間グループ
  - `-`: 水平ズームアウト
  - `全体`: 水平方向を全体表示へ戻す
  - `+`: 水平ズームイン
- 表示位置グループ
  - 全体期間バー: 全体期間内で現在の表示範囲を示す
  - 全体期間バーのクリック: クリック位置を中心に水平表示範囲を移動する
  - 選択イベントがある場合は、全体期間バー上に選択イベントの期間を短いマーカーで示す
  - 狭い画面では全体期間バーを隠し、固定操作エリアの占有を抑える
- 表示プリセット
  - `年`: 抽象時系列の 12 か月分（372日）を表示する
  - `月`: 抽象時系列の 1 か月分（31日）を表示する
  - `詳細`: 7日分を表示する
  - 選択イベントがある場合は選択イベントを中心にし、ない場合は現在の中心を維持する
  - `戻る`: 選択中イベントの位置へ戻る。横方向は必要最小限だけ移動し、対象レーンが表示中なら縦方向もスクロールする
- 密度グループ
  - `-`: レーン密度を下げる
  - `100%`: レーン密度を初期値へ戻す
  - `+`: レーン密度を上げる

## キーボード操作

- `→` / `←`
  - 現在の表示幅に対して一定比率で水平移動
- `+` / `=`
  - 水平ズームイン
- `-` / `_`
  - 水平ズームアウト
- `/`
  - 左メニューを開き、イベント検索欄へフォーカスする
- `N` / `P`
  - 現在の検索・絞り込み済みイベントを次 / 前へ移動する
  - 検索・絞り込みがない場合も、現在表示対象の canonical ID 単位の移動リストを対象にする
  - 末尾と先頭は循環する
  - 移動後はメニューを閉じ、描画されている選択イベントへフォーカスを移す
- `R`
  - 選択中イベントへ戻る
- `Escape`
  - マニュアル、設定、メニュー、詳細パネルの順で、現在開いている操作面を1つ閉じる

`Escape` 以外のアプリショートカットは、フォーム入力中または `contenteditable` では発火しません。IME 変換中、`Ctrl` / `Alt` / `Meta` 付きキー入力では、`Escape` も含めてアプリショートカットを発火させず、ブラウザや OS の操作を優先します。

## ホイール / タッチ操作

- SVG 上でホイールするとカーソル位置基準の水平拡大縮小を行います
- `Ctrl` を押しながらホイールすると縦方向のレーン密度を調整します
- 横方向ホイールでは水平方向に移動します
- マウスドラッグでタイムライン領域を上下左右に移動します
- タッチでは 1 本指ドラッグを上下左右の移動として扱います
- タッチでは 2 本指ピンチを横方向の拡大縮小とレーン密度の同時調整として扱います
- 横方向はピンチアウトで拡大、ピンチインで縮小します
- 縦方向はピンチインでレーン密度が上がり、ピンチアウトで下がります
- レーン密度は、描画中のイベントバーや件数マーカーに必要な高さへ追加する余白量を連続的に調整します
- レーン密度の操作下限は 25% です
- 実際のレーン高さは、イベントバー1本と固定の上下余白だけで表示できる高さを下回りません
- レーン密度を変えても、レーン上端から最上イベントまでの余白と、重なりイベント同士のサブレーン間隔は変えません
- 低密度では、2 段以上に分かれる近接イベントも件数マーカーへ置換し、不要な縦段を残さないようにします
- 高密度では、レーン高さに応じて個別表示できるサブレーン数と近接イベント数の許容量を増やします
- 密集イベントが件数マーカーへ置換される場合、レーン高さは置換後に描画されるサブレーン数に合わせます

## 月/日表示

- 水平ズームと表示 viewport 幅から計算したピクセル密度が十分な場合、月ラベルを表示します
- さらに日ごとの間隔が十分に広い場合、日付（1〜31）を薄いテキストで補助表示します
- 実カレンダーの日数差ではなく、前後関係を見やすくするために1か月=31日換算で扱います
- 月ラベルは `◯月` 表記で 1 日目位置の上部に表示されます

## イベントの選択

- イベント（期間バー領域）をクリックすると、そのイベントが選択状態になります
- 選択中イベントは元のイベント色を保ったまま、太いアウトラインで強調します
- デスクトップでは右側の固定パネル（`aside.side-panel`）、モバイル幅では下部パネルが開き、タイトル、レーン、期間、発生形式、世界線、参加者、出典、注記、詳細が表示されます
- 詳細パネルの項目名とセクション見出しは、マウスオーバーまたはキーボードフォーカスで項目説明を表示します
- 発生形式は `continuous` / `singleWithinRange` の形を示し、日付確度・根拠・出典状態は別項目として表示します
- `dateConfidence`、`sourceBasis`、`sourceStatus`、`rangeReason` がある場合は日本語ラベルで表示し、内部 enum 値は表示しません
- `sourceDetails` がある場合は出典ごとの ID、状態、対象、主張を表示します。件数が多い場合は先頭数件と残件数を表示し、残件は展開できます
- `conflicts` がある場合は出典矛盾として独立した節に表示します
- 詳細パネルは選択中イベントの色を細いアクセントとして表示します
- 詳細パネルの出典と世界線は、データがない場合に未設定として表示します
- 詳細パネルの **URLをコピー** は canonical ID を使った絶対URLをクリップボードへコピーします
- クリップボードへコピーできない場合は、共有URLを選択できる手動コピー欄を表示します
- モバイル幅では、閉じる操作、レーン集中、比較追加、URLコピーを詳細パネル上部にまとめ、本文スクロール中も最初に到達しやすくします
- 詳細パネルの出典チップと出典詳細は、同じ出典キーでイベントを絞り込めます
- 詳細パネルの関連コンテキストは、表示中の同時期イベント、同じレーン、同時期の共通イベント、同じ出典、同じ参加者のイベントを根拠別に表示します
- 関連コンテキストは canonical ID 単位で重複をまとめ、共通イベントは選択中イベントと同じレーンの表示インスタンスを優先します
- 関連コンテキストは時期や登録フィールドに基づく参照であり、因果関係やストーリー解釈を示しません
- `continuous` は継続区間として表示します
- `singleWithinRange` は「期間内のどこか1日」または「月中のいずれか1日」として表示します
- 未指定の `singleWithinRange` は日付確度 `期間内の1日` として扱い、具体日が確定したようには表示しません
- イベントバー内のラベルは、表示中のバー幅と高さに収まる場合だけ表示します
- レーン密度を変えても、イベントバー、密集イベントマーカー、選択アウトライン、フォーカス表示、不確定表示の縦サイズ、レーン上端から最上イベントまでの余白、重なりイベント同士の縦間隔は拡大しません
- ラベルが収まりきらない場合は省略し、マーカー領域を侵すほど狭い場合は非表示にします
- 共通イベントは通常時に小さな菱形の印を表示し、選択中、フォーカス中、またはマウスオーバー中のみイベント名ラベルを表示します
- ズームアウト時に近接イベントが密集する場合、描画上の件数マーカーへ置換します
- 低密度では、通常密度より少ない件数でも、複数サブレーンに分かれる近接イベントを件数マーカーへ置換します
- 高密度では、縦方向に表示できるサブレーン数が増えるため、同じ近接イベント群でも個別イベントとして表示されやすくなります
- 件数マーカーへ置換されたイベント群は、圧縮後の表示量としてレーン高さ計算に使います
- レーン高さの最小必要量は、最初の1本をイベントバーの高さで数え、2本目以降だけサブレーン間隔を追加して計算します
- 密集イベントマーカーは実イベントではなく、選択URLや詳細パネルの対象にはしません
- 密集イベントマーカーをクリックまたは Enter / Space で開くと、含まれる実イベント一覧と範囲拡大ボタンを表示します
- `singleWithinRange` の密集は通常イベントと分け、「期間内」の候補範囲として表示し、具体日を示しません
- マウスオーバーまたはキーボードフォーカス時のツールチップは、タイトル、詳細、コミュ、時期、発生形式、日付確度、根拠分類、出典状態、範囲理由を表示します
- ヘッダー、メニュー、設定、マニュアル、詳細パネル、ズーム操作 UI、案内カード、イベント本体以外をクリック / タップすると詳細パネルを閉じます
- タイムライン上では、イベント以外の領域をクリック / タップすると詳細パネルを閉じます
- ズーム操作 UI（`.zoom-panel`, `.zoom-controls`）は、詳細パネルを開いたまま使えます
- 検索・絞り込みで選択中イベントが非表示になっても、選択状態と URL は維持します
- 非表示になった選択中イベントは、詳細パネル内に現在条件では非表示であることを表示します

## 期間内の単日イベント

- `occurrenceType: "singleWithinRange"` のイベントは「期間内のどこか1日」で発生することを示します
- タイムライン上ではバーが破線になり、両端に不確定マーカーが表示されます
- これは候補期間を示すためであり、中央日付を意味しません
- `dateConfidence: "inferred"` は推定、`sourceStatus: "conflicting"` または `conflicts` は出典矛盾として詳細パネルと検索で区別します

## 開始点・終了点マーカー

- 期間バーの開始点と終了点に丸マーカーを表示します
- 開始点・終了点ともにイベントの表示ロールに沿った色で表示されます
- 共通イベントは専用の中立色で表示し、レーンとの関係は境界線や詳細パネルのアクセントで示します

## 描画フィールド

- タイムライン描画領域は矩形で囲われます
- イベントや目盛りは `clipPath` により領域外へ描画されません
- タイムラインのスクロール内容末尾に広告枠を置き、レーン数が少ない場合は上側の空きが伸びて広告枠が途中まで上がらないようにします
- 開発時の描画メトリクス表示は `debugMetrics` が有効な dev build だけに出し、通常の操作対象、選択状態、共有URL、詳細パネル、密集イベント summary の意味には含めません

## URL 同期

選択状態と共有可能な表示状態は URL クエリに反映されます。

- 選択: `?event=<eventId>` を付与
- 閉じる: `event` クエリを削除
- 詳細パネルの共有URL: 現在の絶対URLに `?event=<canonicalId>` を反映

実装は `history.replaceState` のため、ページ遷移せず URL だけ更新されます。

共通イベントは表示上はレーンごとに複製されますが、URL には canonical ID を使います。

イベント検索、イベント絞り込み、表示レーン、レーン集中表示、レーン比較表示、水平表示範囲、レーン密度は `view=1` の追加クエリとして URL に同期します。

レーン集中表示は `focus=<laneId>`、レーン比較表示は `compare=<laneId,laneId,...>` で表します。`focus` は既存URL互換のため単一レーン専用のまま残します。

デフォルト状態は URL から省略します。表示レーンは URL 長を抑えるため、表示IDまたは非表示IDの短い方を `lm=include|exclude` と `lanes=<id,...>` で表します。

レーン検索欄の文字列はメニュー内の一時入力として扱い、URL には同期しません。

配色、操作ヒント、初見向け案内カードの状態は個人設定として扱い、共有URLには含めません。共通イベント表示は通常URL同期では個人設定のままですが、表示条件バーの共有URLには必要な場合だけ含めます。

## 初回ロード時の復元

初回マウント時に URL クエリの `event` を読み、該当 canonical ID のイベントが存在すれば自動的に選択します。

`view=1` がある場合は、カテゴリ、表示レーン、イベント検索、絞り込み、レーン集中表示、レーン比較表示、水平表示範囲、レーン密度を復元します。無効または古いIDは無視し、復元できる状態だけを適用します。

選択中イベントがイベント検索・絞り込み・比較表示で非表示になっても、選択状態と詳細パネルは維持します。

## 表示ラベル

年表示は `yearLabel(year)` が変換します。

- `1` → `1年目`
- `2` 以上 → `n年目`
- `0` 以下 → `n年前`（`1 - year` を `n` として扱う）

## ヘッダーとサイドメニュー

- 上部に固定ヘッダーを表示し、左のアイコンからメニューを開きます
- ヘッダーにはメニュー、マニュアル、設定の各ボタンがあります
- メニューはオーバーレイ/スライド式で開閉し、背景クリックや `Escape` で閉じます
- カテゴリ選択後、該当レーンをチェックボックスで表示/非表示にできます
- レーン検索は現在カテゴリ内のメニュー表示だけを絞り込みます
- 並び替えはレーン一覧とタイムライン上のレーン順の両方に反映されます
- 初期状態ではカテゴリ内のレーンは全て選択されています
- 「表示中を一括」は、検索結果として現在見えているレーンだけに作用します
- 表示レーンが 0 件になっても、横方向の viewport は維持されます
- レーンを再表示した場合は、解除直前の拡大率と表示位置を引き継ぎます
- レーン行の比較操作は表示レーンのチェック状態を変更せず、2〜4件の active lane を一時表示対象にします
- 比較対象が1件だけの場合は比較準備状態として扱い、タイムライン本体は全 active lane 表示のままです
- 比較対象の5件目は自動入れ替えせず、追加を拒否します
- カテゴリ切り替え時はレーン比較表示を解除します

## イベント検索 / 絞り込み

- イベント検索は現在のカテゴリと表示レーン内のイベントだけを対象にします。レーン比較表示中は比較対象レーン内のイベントだけを対象にします
- 検索対象には title、detail、source、note、発生形式、レーン/コミュ名、参加者 ID、参加者名、世界線 ID、世界線名を含めます
- 検索語はスペース区切りの AND 条件として扱います
- 発生形式、日付確度、監査カテゴリ、出典、参加者、コミュ、世界線のフィルタはグループ間 AND として扱います
- 出典、参加者、コミュ、世界線の候補は、現在の表示対象データに存在する場合だけ表示します
- 日付確度フィルタは `confirmed`、`inferred`、`rangeOnly`、`conflicting` の派生状態で扱います
- 監査カテゴリフィルタは、出典矛盾、出典なし、未確認、分類不能、推定、期間内の1日を既存メタデータから複数タグとして派生します
- 出典フィルタは `sourceDetails[].id`、`sourceDetails[].url`、`sourceDetails[].label`、`source[]` から作った出典キーで一致判定します
- 既存互換として、メタデータ未指定の `singleWithinRange` は `rangeOnly` として扱います
- 表示レーン一覧には、レーン所有イベントだけを対象にした出典矛盾、出典なし、推定、期間内の1日の件数サマリーを表示します。共通イベントはこのレーン品質サマリーには含めません
- 共通イベントの表示可否は設定メニューの **共通イベントを表示する** を正とし、検索メニューには重複した共通イベント toggle を置きません
- 共通イベントはレーンごとに描画されますが、検索結果件数と前後移動では canonical ID 単位にまとめます
- **前へ / 次へ** は、検索・絞り込み済みイベントを `displayStartDay`、`displayEndDay`、レーン順、タイトル順で移動します
- キーボードの `N` / `P` も同じ移動対象と並び順を使います
- キーボードの `/` はメニューを開いてイベント検索欄へフォーカスします
- 前後移動で選択したイベントが表示範囲外にある場合は、既存の選択イベント追従により水平方向を調整し、対象レーンが見える位置まで縦スクロールします
- レーンラベルまたは詳細パネルの操作でレーン集中表示に入れます
- レーン集中表示は一時状態であり、表示レーンのチェック状態は変更しません
- 詳細パネルの操作で選択中イベントのレーンを比較対象へ追加できます
- レーン集中表示とレーン比較表示は排他的で、集中表示へ入ると比較表示は解除され、比較対象を追加すると集中表示は解除されます
- 検索、絞り込み、監査カテゴリ、出典、表示レーン、表示範囲、レーン集中表示、レーン比較表示などの有効状態はタイムライン上部の表示条件バーにチップとして表示します
- 表示条件チップの各ボタンで個別に解除できます
- 表示条件バーの **解除** は、選択中イベントを閉じずに表示条件を初期状態へ戻します
- 表示条件バーの **表示URL** は、現在の表示状態を含む共有URLをコピーします

## 設定メニュー

- 設定メニューは右側のスライド式で開閉します
- 配色モードは `system / light / dark` を切り替えできます
- `system` では OS / ブラウザの `prefers-color-scheme` に追従します
- 表示オプションでは、共通イベント表示と操作ヒント表示を切り替えできます

## レーンラベルの配色

- 文字色は公式色または既存データ色から解決した表示ロールを使用します
- 背景色は OKLCH で色相反転＋高明度/低彩度に調整し、必要に応じてコントラストを確保します
- 色の出典と派生ロールの詳細は `docs/color-system.md` にまとめます

## 物語イベントグラフ

`src/pages/StoryGraphPage.vue`は、StoryBlockをHTMLボタン、StoryEdgeをSVGパスとして同じ変形ステージへ描画します。

- `sequence`エッジだけから段を計算し、接続先を接続元より下へ置きます。
- `semantic`エッジは配置計算へ使用しません。
- `sequence`を持たないノードは前後関係未確定領域へ置きます。
- 描画座標、ノード間距離、エッジ長には時間的な意味を持たせません。
- 実線は`sequence`、破線は`semantic`を表します。
- `forward`は終点側、`bidirectional`は両端に矢印を表示します。
- `undirected`は矢印を表示しません。
- ノードとエッジはポインターとキーボードの両方で選択できます。
- ノード選択は`node`、エッジ選択は`edge`へ保存し、同時には使用しません。
- 絞り込み結果が変わると、表示中の全体が収まる倍率へ調整します。
- 狭い画面では詳細パネルを画面下部へ配置します。
