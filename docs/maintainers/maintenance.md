# 保守メモ

このドキュメントは、AI / 保守作業者が実装修正時に共有しておきたい設計ルールをまとめたものです。

## 時間表現

- 月は実カレンダーではなく、常に31日換算で扱います
- 年月は `timeValue(year, month)`、年月日は `dayTimeValue(year, month, day)` で内部時刻へ変換します
- 画面上の描画・可視判定・選択フォーカスは `displayStartDay` / `displayEndDay` を使います

## イベント表現

- `continuous`
  - `start` から `end` まで継続する期間イベントです
- `singleWithinRange`
  - `start` から `end` の間のどこか1日で発生するイベントです
  - 中央日付は持たず、バーと不確定マーカーで候補期間を示します

## イベント ID

- 通常イベントは `id` をそのまま `canonicalId` として使います
- 共通イベントは各レーンに複製されます
- URL 共有には `canonicalId` を使います
- 描画キーや「今見えている複製個体」の識別には `instanceId` を使います

## データ補完ルール

- `id` がないイベントにはフォールバック ID を付与します
- `title` がないイベントは `(無題)` を補完します
- `detail` がないイベントは空文字列を補完します
- `start` / `end` に年または月がないイベントは表示対象から除外します

現時点では、これ以上の固定データルールは置きません。

## 命名と責務の原則

- 表示用の派生時刻は `display*` 接頭辞を使います
- URL 共有用 ID は `canonicalId`、描画インスタンス識別は `instanceId` を使います
- 描画コンポーネントでは、データ補完や ID 補完を行わず、描画責務に寄せます
- 複数箇所で使う派生計算は helper / composable に集約します

## 修正時に壊れやすい箇所

- `useTimelineData.js`
  - イベント派生値の正規化
- `useTimelineLayout.js`
  - 可視判定、サブレーン計算、座標変換
- `useZoomMachine.js`
  - 表示範囲、選択時フォーカス、ラベル表示閾値
- `usePointer.js`
  - ドラッグ、クリック抑止、タッチ操作
- `useSelection.js`
  - URL 復元、共通イベント選択

## ドキュメント同期が必要な変更

- UI や表示の変更に伴う `docs/manual.md` の更新
- 入力操作の変更
- 拡大縮小仕様の変更
- ラベル表示やイベント表現の変更
- `occurrenceType` の意味変更
- URL 共有仕様の変更

上記以外のドキュメントは、変更内容と既存記述を照らし合わせて必要なものだけ更新します。

## 確認方針

- `npm run build` は最低確認に含めます
- それとは別に、実機ブラウザ確認を必須とします
- 実機確認の優先環境は Windows Chrome、次にスマホ表示です

## 変更禁止領域

- キャラ名やコミュ文言は、UI 修正のついでに直しません
- データ内容の意味変更は、明示的な依頼がない限り行いません
