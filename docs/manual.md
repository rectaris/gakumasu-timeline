# 操作マニュアル

このマニュアルは、タイムラインアプリの現在の操作方法をまとめたものです。

## 画面構成

- **固定ヘッダー**: 画面上部に固定表示
  - 左: メニュー（☰）、マニュアル（？）
  - 中央: タイトル
- **左メニュー**: カテゴリとレーンの表示切り替え
- **ズーム操作エリア**: 水平 `H`、垂直 `V` の表示調整
- **タイムライン**: レーンごとのイベントを時系列に表示
- **詳細パネル**: 右側にイベント詳細を表示

## メニュー操作

1. ヘッダー左の **☰** をクリックしてメニューを開きます。
2. **カテゴリ** を選択します。
3. **表示レーン** のチェックで表示/非表示を切り替えます。
4. **一括** チェックでカテゴリ内の全レーンをまとめて選択/解除できます。
5. 背景クリック、または **Escape** キーでメニューを閉じます。

補足:

- 初期状態では、選択中カテゴリのレーンはすべて表示されています。

## タイムライン操作

- **イベント選択**: バーをクリックすると右の詳細パネルに内容が表示されます。
- **ツールチップ**: マウスオーバーで `title` と `detail` が表示されます。
- **詳細パネルを閉じる**: 右上の × または **Escape** キー。

## ズーム・移動操作

### 水平方向

- **H -**: 水平ズームアウト
- **H 全体**: 全イベントが入る表示幅に戻す
- **H +**: 水平ズームイン
- **マウスホイール**: カーソル位置基準で水平拡大・縮小
- **横方向ホイール**: 水平方向に移動
- **マウスドラッグ**: 左右に移動
- **キーボード ← / →**: 表示範囲を左右に移動
- **キーボード + / -**: 水平ズームイン / アウト
- **タッチ操作**: タイムライン上で横ドラッグすると水平移動

### 垂直方向

- **V -**: レーン密度を下げる
- **V 100%**: 縦倍率を初期値へ戻す
- **V +**: レーン密度を上げる

### 自動調整

- イベントを選択した時、そのイベントが現在の表示範囲に収まっていなければ、自動で収まる幅まで調整されます。

## イベントの見え方

- **通常イベント (`continuous`)**
  - 開始から終了まで続く期間として表示されます。
- **期間内のどこか1日イベント (`singleWithinRange`)**
  - 破線バーで表示されます。
  - 両端に不確定マーカーが付きます。
  - これは候補期間を示すもので、中央日付を意味しません。
- **丸マーカー**
  - 開始点・終了点を示します。

## 詳細パネルの見方

- `continuous` は継続区間として表示されます。
- `singleWithinRange` は「期間内のどこか1日」または「月中のいずれか1日」として表示されます。
- URL に `?event=<eventId>` が付くため、選択状態の共有ができます。

## 日付表示の仕様

- 実暦は考慮せず、**1か月=31日** として扱います。
- 月ラベルは `◯月` 表示です。
- 日付ラベル（1〜31）は、十分にズームインしたときのみ表示されます。

## 既知の仕様

- このタイムラインは創作世界向けの抽象時系列であり、実在カレンダーの月日とは一致しない場合があります。
- 共通イベントは複数レーンに表示されますが、URL 共有には共通のイベント ID を使います。
