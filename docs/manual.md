# 操作マニュアル

このマニュアルは、タイムラインアプリの現在の操作方法をまとめたものです。

## ビューの選択

ヘッダーの「表示」から、独立した3つのビューを選択します。

- 「物語時系列」は、キャラクターやストーリーの出来事をレーン型タイムラインで表示します。
- 「物語イベント」は、ゲーム内の1つのコミュを1ノードとして前後関係と意味的関係を表示します。
- 「学マス情報史」は、現実世界の情報史として表示境界だけを用意しており、内容は開発準備中です。

表示を切り替えるとブラウザ履歴に残るため、戻る操作と進む操作で以前のビューへ移動できます。

## 画面構成

- **固定ヘッダー**: 画面上部に固定表示
  - 左: メニュー（☰）、マニュアル（？）、設定（⚙）
  - 中央: タイトル
- **初見向け案内カード**: 初回表示時に、最初に触る操作を 3 ステップで案内
- **左メニュー**: カテゴリ、レーン表示、イベント検索、イベント絞り込み
- **表示条件バー**: 検索・絞り込み・表示範囲などが有効な時に、タイムライン上部に現在の状態を表示
- **右設定メニュー**: 配色モードや表示オプションの切り替え
- **ズーム操作エリア**: タイムライン画面下部にある操作ボタン群
  - **表示期間ボタン**: どのくらいの期間を画面に表示するか調整するボタン群
  - **全体期間バー**: 全体の中で現在どこを見ているかを示す小さなバー
  - **表示プリセット**: 年、月、詳細の幅へすばやく切り替えるボタン群
  - **レーン密度ボタン**: レーンの詰まり具合を調整するボタン群
- **タイムライン**: レーンごとのイベントを時系列に表示
- **広告エリア**: タイムライン内容の末尾に配置される広告枠
- **詳細パネル**: デスクトップでは右側、モバイル幅では画面下部にイベント詳細を表示

## 物語イベントの操作

「物語イベント」は`?mode=story-graph`で直接開けます。

- ノードはゲーム内の1つのコミュを表します。
- 実線は物語上の前後関係を表し、上から下へ進みます。
- 破線は参照や代替などの意味的関係を表し、ノードの配置順を変えません。
- 矢印なし、片側矢印、両側矢印で、無方向、片方向、双方向を区別します。
- 前後関係が未確定の話は「前後関係が未確定」の領域へ表示します。
- ノード間距離と線の長さは、時間差を表しません。

ノードまたは線を選ぶと、デスクトップでは右側、狭い画面では下側に詳細が開きます。
ノード詳細ではカテゴリ、階層、人物タグ、物語上の位置を確認できます。
線の詳細では接続元、接続先、方向、関係種別、確度、登録理由を確認できます。

検索欄は、話のタイトル、シリーズ、人物を対象にします。
カテゴリと人物の選択欄は検索条件と組み合わせて使用できます。

空き領域のドラッグでグラフを移動し、ホイールまたは左下の操作で拡大縮小します。
「全体」は、現在の絞り込み結果が画面へ収まる状態に戻します。
キーボードの`+`、`-`、`0`でも拡大、縮小、全体表示を操作できます。

ノードへキーボードフォーカスを移すと、上下キーで前後関係に沿って移動できます。
左右キーでは表示中の隣接ノードへ移動します。
線もTabキーでフォーカスでき、EnterキーまたはSpaceキーで詳細を開けます。

ノード選択は`node=<StoryBlock ID>`、線の選択は`edge=<StoryEdge ID>`としてURLへ保存されます。
共有URLの再読込とブラウザの戻る操作または進む操作で選択を復元できます。

MVPで表示する内容はデータ形式と操作を検証する代表データです。
全コミュの収録完了や、仮表示として登録した意味的関係の確定を示すものではありません。

## 初見向け案内カード

1. 初回表示では、画面左上に「まずは 3 ステップで見始められます」という案内カードが表示されます。
2. **表示レーンを見る** を押すと、左メニューを開いてカテゴリやレーン選択へ進めます。
3. 案内カードでは、画面下部の **期間 / 密度** 操作とホイールで範囲を調整できることも示されます。
4. **操作マニュアルを見る** を押すと、マニュアルをそのまま開けます。
5. 右上の **×** で案内カードを閉じると、そのブラウザでは以後は自動で閉じた状態を保ちます。

## メニュー操作

1. ヘッダー左の **☰** をクリックしてメニューを開きます。
2. **カテゴリ** を選択します。
3. **検索** でレーン名を絞り込み、**並び替え** で表示順を変更できます。
4. **表示レーン** のチェックで表示/非表示を切り替えます。
5. **表示中を一括** チェックで、現在表示中のレーンだけをまとめて選択/解除できます。
6. 並び替えは、メニュー内の順番だけでなくタイムライン上のレーン順にも反映されます。
7. レーン行の **比較** で、2〜4件のレーンを一時的に比較表示できます。
8. **イベント検索** で、現在のカテゴリと表示レーン内のイベントを探せます。比較表示中は比較対象レーン内だけを対象にします。
9. 検索語はスペース区切りで追加できます。すべての語に一致するイベントだけが残ります。
10. 発生形式、日付確度、参加者、コミュ、世界線の候補がある場合は、追加で絞り込めます。
11. **前へ / 次へ** で、現在の検索・絞り込み結果を時系列順に移動できます。
12. キーボードの **/** でもメニューを開いてイベント検索欄へ移動できます。
13. 背景クリック、または **Escape** キーでメニューを閉じます。

補足:

- 初期状態では、選択中カテゴリのレーンはすべて表示されています。
- 表示レーンをすべて外しても、横方向の拡大率と表示位置は保持されます。
- レーンを再度表示すると、解除直前の表示状態で再開されます。
- 比較表示は表示レーンのチェック状態を変更しません。カテゴリを切り替えると解除されます。
- イベント検索、絞り込み、表示レーン、比較表示、表示範囲などの表示状態は URL に反映されます。
- 表示条件バーの **表示URL** から、現在の表示状態を含む共有URLをコピーできます。
- 表示条件バーの **解除** は、選択中イベントを残したまま表示条件を初期状態に戻します。
- 共通イベントは複数レーンに表示されますが、検索結果の前後移動では同じイベント ID を 1 件として扱います。

## 設定メニュー

1. ヘッダー左の **⚙** をクリックして設定を開きます。
2. **配色モード** で以下を選べます。
   - **システム設定に合わせる**: OS / ブラウザのモードに追従
   - **ホワイトモード**
   - **ダークモード**
3. **表示オプション** で以下を切り替えられます。
   - **共通イベントを表示する**
   - **操作ヒントを表示する**
4. 背景クリック、または **Escape** キーで設定を閉じます。

## タイムライン操作

- **イベント選択**: バーをクリックすると右の詳細パネルに内容が表示されます。
- **詳細パネル**: レーン、期間、発生形式、日付確度、根拠、出典状態、世界線、参加者、出典、注記、詳細文を確認できます。項目名にマウスオーバーまたはキーボードフォーカスすると説明が表示されます。出典または世界線が未設定のイベントは、未設定として表示されます。
- **URL共有**: 詳細パネルの **URLをコピー** から、選択中イベントを復元できる共有URLをコピーできます。
- **表示状態の共有**: 表示条件バーの **表示URL** から、検索・絞り込み・表示範囲などを復元できる共有URLをコピーできます。
- **関連コンテキスト**: 詳細パネルには、表示中の同時期イベント、同じレーン、同時期の共通イベント、同じ参加者のイベントが表示される場合があります。これは参照用であり、因果関係を示すものではありません。
- **イベント検索からの移動**: 左メニューの **前へ / 次へ** でイベントを選ぶと、そのイベントの位置へ移動します。
- **キーボードでの検索移動**: **/** でイベント検索欄へ移動し、**N / P** で現在の検索・絞り込み結果を次 / 前へ移動できます。
- **レーン集中表示**: レーンラベル、または詳細パネルの **このレーンに集中** から、対象レーンだけを一時表示できます。
- **レーン比較表示**: メニューの **比較**、または詳細パネルの **比較に追加** から、2〜4件のレーンを一時表示できます。
- **密集イベント**: ズームアウト時に近接イベントが件数マーカーへまとまる場合があります。マーカーを開くと含まれる実イベントを選択できます。
- **ツールチップ**: マウスオーバーまたはキーボードフォーカスで、タイトル、詳細、コミュ、時期、発生形式、日付確度、根拠、出典状態などの説明が表示されます。
- **詳細パネルを閉じる**: 右上の × または **Escape** キー。
- **外側クリック / タップ**: ヘッダー、メニュー、設定、マニュアル、詳細パネル、ズーム操作、イベント、レーン操作以外をクリック / タップすると閉じます。
- **タイムライン上の空き領域**: イベント以外の領域をクリック / タップすると閉じます。
- **ズーム操作は継続可能**: 詳細パネルを開いたまま、画面下部の期間 / 密度ボタンやホイール操作を使えます。
- **広告の位置**: 広告はタイムライン内容の下部に配置され、表示レーンが少ない時は下部余白が伸びて途中まで上がらないように調整されます。

## ズーム・移動操作

### 表示期間の調整

- 画面下部の**期間ボタン**は、「どのくらいの期間を画面に表示するか」を調整する列です。
- **表示期間の `-`**: 水平ズームアウト
- **表示期間の `全体`**: 全イベントが入る表示幅に戻す
- **表示期間の `+`**: 水平ズームイン
- **全体期間バー**: 現在の表示範囲を全体期間内の位置として表示します。クリックした位置を中心に移動できます。
- **選択イベントマーカー**: イベント選択中は、全体期間バー上に選択イベントの期間が短いマーカーで表示されます。
- **表示プリセット `年`**: 12 か月分（372日）を表示します。
- **表示プリセット `月`**: 1 か月分（31日）を表示します。
- **表示プリセット `詳細`**: 7日分を表示します。
- **`戻る`**: 選択中イベントへ戻ります。横方向は必要な分だけ移動し、対象レーンが表示中なら縦方向にもスクロールします。
- **マウスホイール**: カーソル位置基準で表示期間を拡大・縮小
- **Ctrl + ホイール**: レーン密度（縦軸）を調整
- **横方向ホイール**: 水平方向に移動
- **マウスドラッグ**: タイムライン領域を上下左右に移動
- **キーボード ← / →**: 表示範囲を左右に移動
- **キーボード + / -**: 表示期間を拡大 / 縮小
- **キーボード /**: メニューを開いてイベント検索欄へ移動
- **キーボード N / P**: 現在の検索・絞り込み結果を次 / 前へ移動
- **キーボード R**: 選択中イベントへ戻る
- **Escape**: マニュアル、設定、メニュー、詳細パネルの順で、現在開いている操作面を閉じる
- **タッチ操作**: 1本指ドラッグで上下左右に移動
- **タッチ操作**: 2本指ピンチで表示期間とレーン密度を同時に調整
- **横方向**: ピンチアウトで拡大、ピンチインで縮小
- **縦方向**: ピンチインでレーン密度を上げ、ピンチアウトで下げる

### レーン密度の調整

- 画面下部の**密度ボタン**は、「レーンの詰まり具合」を調整する列です。
- **レーン密度の `-`**: レーン密度を下げる
- **レーン密度の `100%`**: レーン密度を初期値へ戻す
- **レーン密度の `+`**: レーン密度を上げる
- レーン密度の操作下限は 25% です。
- 実際のレーン高さは、イベントバー1本と固定の上下余白だけで表示できる高さを下回りません。
- レーン密度の上限は、FHD 画面で 1 レーンを最大表示できる高さを基準にします。
- レーン密度は、描画中のイベントバーや件数マーカーに追加する余白量を連続的に変えます。
- レーン密度を変えても、レーン上端から最上イベントまでの余白と、同じレーン内で上下に並ぶ重なりイベント同士の間隔は変わりません。
- 低密度では、2 段以上に分かれる近接イベントも件数マーカーへまとまり、レーンの高さもまとまった後の表示量に合わせて縮みます。
- 高密度では、縦方向に個別表示できるイベント量が増えるため、同じ密集イベントでも件数マーカーから個別表示に戻りやすくなります。

### 自動調整

- イベントを選択した時、そのイベントが現在の表示範囲に収まっていなければ、自動で収まる幅まで調整されます。
- 検索結果の前後移動でイベントを選択した時は、対象レーンが見える位置まで縦方向にも移動します。
- 詳細パネルを開いた状態でも、ズーム操作エリアのクリックではパネルは閉じません。

## イベントの見え方

- **イベント名ラベル**
  - バーに十分な幅と高さがある時だけ、イベント名がバー上に表示されます。
  - レーン密度を変えても、イベントバーや選択表示の縦サイズ、レーン上端から最上イベントまでの余白、重なりイベント同士の縦間隔は拡大しません。
  - 幅が足りない場合は省略表示になり、さらに狭い場合はラベルを隠します。
  - 選択中、キーボードフォーカス中、またはマウスオーバー中は、バー付近に一時的なイベント名ラベルが表示されます。
- **通常イベント (`continuous`)**
  - 開始から終了まで続く期間として表示されます。
- **選択中イベント**
  - 元のイベント色を保ったまま、太いアウトラインで強調されます。
- **期間内のどこか1日イベント (`singleWithinRange`)**
  - 破線バーで表示されます。
  - 両端に不確定マーカーが付きます。
  - これは候補期間を示すもので、中央日付を意味しません。
  - 詳細パネルでは日付確度が「期間内の1日」として表示されます。
- **密集イベントマーカー**
  - ズームアウト時に近いイベントを件数でまとめます。
  - レーン密度を上げると、縦方向に表示できる量が増えるため、同じ密集イベント群でも個別表示に戻りやすくなります。
  - `singleWithinRange` は通常イベントと混ぜず、「期間内」と分かる表示にします。
  - マーカー自体は実イベントではなく、URL共有や詳細パネルでは個別イベントを選びます。
- **共通イベント**
  - 専用の中立色で表示され、レーンとの関係は境界線や詳細パネルのアクセントで示します。
  - 通常時は小さな菱形の印で共通イベントであることを示し、選択中やマウスオーバー中にイベント名を表示します。
- **丸マーカー**
  - 開始点・終了点を示します。

## 詳細パネルの見方

- `continuous` は継続区間として表示されます。
- `singleWithinRange` は「期間内のどこか1日」または「月中のいずれか1日」として表示されます。
- 日付確度には「確定」「推定」「期間内の1日」「出典矛盾」が表示される場合があります。
- 出典ごとの ID、主張、対象、未解決の矛盾があるイベントでは、出典詳細や出典矛盾の節が表示されます。
- 出典チップや出典詳細の出典名を選ぶと、同じ出典キーを持つイベントで絞り込めます。
- 出典詳細が多い場合は、残りの件数を選ぶと全件を展開できます。
- 関連コンテキストには、同じ出典、同じ参加者、同時期などの根拠別候補が表示されます。これは参照関係を示すもので、因果関係を示すものではありません。
- モバイル幅では詳細パネルが画面下部に表示され、タイトル、閉じる操作、レーン集中、比較追加、URLコピーが上部にまとまります。
- 選択中イベントが検索・絞り込み・比較表示などの条件で非表示になった場合でも、詳細パネルは閉じずに非表示状態を示します。
- URL に `?event=<eventId>` が付くため、選択状態の共有ができます。
- 検索・絞り込み・表示レーン・比較表示・表示範囲などが有効な場合は、追加の URL パラメータで表示状態も復元されます。

## 証拠品質の確認

- メニューのイベント検索では、監査フィルタから「出典矛盾」「出典なし」「未確認」「分類不能」「推定」「期間内の1日」を選べます。
- 監査フィルタは、既存の発生形式、確度、出典、参加者、コミュ、世界線の条件と AND 条件で組み合わされます。
- 出典フィルタでは、現在の表示対象データに存在する出典からイベントを絞り込めます。
- 表示レーン一覧には、レーンごとの出典矛盾、出典なし、推定、期間内の1日の件数が短く表示されます。

## 日付表示の仕様

- 日付ラベルは実際の月日ではなく、前後関係を見やすくするために**1か月=31日**換算で並べた抽象時系列として扱います。
- 月ラベルは `◯月` 表示です。
- 月ラベルと日付ラベル（1〜31）は、画面上で十分な間隔がある時だけ表示されます。
- 配色モードが **システム設定に合わせる** の場合、ページ全体の配色はユーザー環境に追従します。

## 既知の仕様

- このタイムラインは創作世界向けの抽象時系列であり、実在カレンダーの月日や日数差を正確に再現するものではありません。
- 共通イベントは複数レーンに表示されますが、URL 共有には共通のイベント ID を使います。
