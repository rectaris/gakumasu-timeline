# 操作マニュアル

このマニュアルは、タイムラインアプリの現在の操作方法をまとめたものです。

## 画面構成

- **固定ヘッダー**: 画面上部に固定表示
  - 左: メニュー（☰）、マニュアル（？）、設定（⚙）
  - 中央: タイトル
- **初見向け案内カード**: 初回表示時に、最初に触る操作を 3 ステップで案内
- **左メニュー**: カテゴリとレーンの表示切り替え
- **右設定メニュー**: 配色モードや表示オプションの切り替え
- **ズーム操作エリア**: タイムライン画面下部にある操作ボタン群
  - **表示期間ボタン**: どのくらいの期間を画面に表示するか調整するボタン群
  - **レーン密度ボタン**: レーンの詰まり具合を調整するボタン群
- **タイムライン**: レーンごとのイベントを時系列に表示
- **広告エリア**: タイムライン内容の末尾に配置される広告枠
- **詳細パネル**: 右側にイベント詳細を表示

## 初見向け案内カード

1. 初回表示では、画面左上に「まずは 3 ステップで見始められます」という案内カードが表示されます。
2. **表示レーンを見る** を押すと、左メニューを開いてカテゴリやレーン選択へ進めます。
3. 案内カードでは、画面下部の **表示期間（横軸） / レーン密度（縦軸）** 操作とホイールで範囲を調整できることも示されます。
4. **操作マニュアルを見る** を押すと、マニュアルをそのまま開けます。
5. 右上の **×** で案内カードを閉じると、そのブラウザでは以後は自動で閉じた状態を保ちます。

## メニュー操作

1. ヘッダー左の **☰** をクリックしてメニューを開きます。
2. **カテゴリ** を選択します。
3. **検索** でレーン名を絞り込み、**並び替え** で表示順を変更できます。
4. **表示レーン** のチェックで表示/非表示を切り替えます。
5. **表示中を一括** チェックで、現在表示中のレーンだけをまとめて選択/解除できます。
6. 並び替えは、メニュー内の順番だけでなくタイムライン上のレーン順にも反映されます。
7. 背景クリック、または **Escape** キーでメニューを閉じます。

補足:

- 初期状態では、選択中カテゴリのレーンはすべて表示されています。
- 表示レーンをすべて外しても、横方向の拡大率と表示位置は保持されます。
- レーンを再度表示すると、解除直前の表示状態で再開されます。

## 設定メニュー

1. ヘッダー左の **⚙** をクリックして設定を開きます。
2. **配色モード** で以下を選べます。
   - **システム設定に合わせる**: OS / ブラウザのモードに追従
   - **ホワイトモード**
   - **ダークモード**
3. **表示オプション** で以下を切り替えられます。
   - **共通イベントを表示する**
   - **操作ヒントを表示する**
4. 背景クリック、または **Escape** キーで設定を閉じます。

## タイムライン操作

- **イベント選択**: バーをクリックすると右の詳細パネルに内容が表示されます。
- **閉じ方の案内**: 開いた詳細パネル内に、Escape キーまたは外側のクリック / タップで閉じられる案内が表示されます。
- **ツールチップ**: マウスオーバーで `title` と `detail` が表示されます。
- **詳細パネルを閉じる**: 右上の × または **Escape** キー。
- **外側クリック / タップ**: ヘッダー、メニュー、設定、マニュアル、詳細パネル以外をクリック / タップしても閉じます。
- **タイムライン上の空き領域**: イベント以外の領域をクリック / タップすると閉じます。
- **ズーム操作は継続可能**: 詳細パネルを開いたまま、画面下部の表示期間（横軸） / レーン密度（縦軸）ボタンやホイール操作を使えます。
- **広告の位置**: 広告はタイムライン内容の下部に配置され、表示レーンが少ない時は下部余白が伸びて途中まで上がらないように調整されます。

## ズーム・移動操作

### 表示期間の調整

- 画面下部の**表示期間（横軸）ボタン**は、「どのくらいの期間を画面に表示するか」を調整する列です。
- **表示期間の `-`**: 水平ズームアウト
- **表示期間の `全体`**: 全イベントが入る表示幅に戻す
- **表示期間の `+`**: 水平ズームイン
- **マウスホイール**: カーソル位置基準で表示期間を拡大・縮小
- **Ctrl + ホイール**: レーン密度（縦軸）を調整
- **横方向ホイール**: 水平方向に移動
- **マウスドラッグ**: タイムライン領域を上下左右に移動
- **キーボード ← / →**: 表示範囲を左右に移動
- **キーボード + / -**: 表示期間を拡大 / 縮小
- **タッチ操作**: 1本指ドラッグで上下左右に移動
- **タッチ操作**: 2本指ピンチで横方向と縦方向を同時に拡大・縮小
- **横方向**: ピンチアウトで拡大、ピンチインで縮小
- **縦方向**: ピンチインでレーン密度を上げ、ピンチアウトで下げる

### レーン密度の調整

- 画面下部の**レーン密度（縦軸）ボタン**は、「レーンの詰まり具合」を調整する列です。
- **レーン密度の `-`**: レーン密度を下げる
- **レーン密度の `100%`**: 縦倍率を初期値へ戻す
- **レーン密度の `+`**: レーン密度を上げる

### 自動調整

- イベントを選択した時、そのイベントが現在の表示範囲に収まっていなければ、自動で収まる幅まで調整されます。
- 詳細パネルを開いた状態でも、ズーム操作エリアのクリックではパネルは閉じません。

## イベントの見え方

- **通常イベント (`continuous`)**
  - 開始から終了まで続く期間として表示されます。
- **選択中イベント**
  - 元のイベント色を保ったまま、太いアウトラインで強調されます。
- **期間内のどこか1日イベント (`singleWithinRange`)**
  - 破線バーで表示されます。
  - 両端に不確定マーカーが付きます。
  - これは候補期間を示すもので、中央日付を意味しません。
- **共通イベント**
  - 専用の中立色で表示され、レーンとの関係は境界線や詳細パネルのアクセントで示します。
- **丸マーカー**
  - 開始点・終了点を示します。

## 詳細パネルの見方

- `continuous` は継続区間として表示されます。
- `singleWithinRange` は「期間内のどこか1日」または「月中のいずれか1日」として表示されます。
- URL に `?event=<eventId>` が付くため、選択状態の共有ができます。

## 日付表示の仕様

- 日付ラベルは実際の月日ではなく、前後関係を見やすくするために**1か月=31日**換算で並べた抽象時系列として扱います。
- 月ラベルは `◯月` 表示です。
- 日付ラベル（1〜31）は、十分にズームインしたときのみ表示されます。
- 配色モードが **システム設定に合わせる** の場合、ページ全体の配色はユーザー環境に追従します。

## 既知の仕様

- このタイムラインは創作世界向けの抽象時系列であり、実在カレンダーの月日や日数差を正確に再現するものではありません。
- 共通イベントは複数レーンに表示されますが、URL 共有には共通のイベント ID を使います。
