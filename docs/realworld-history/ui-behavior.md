# 学マス情報史のUI挙動

- 状態：Approved
- 仕様バージョン：0.2

## 画面の責務

学マス情報史は、現実世界のグレゴリオ暦上で公開済みのInfoEventを閲覧する独立ビューです。
「物語時系列」「物語イベント」と同じ画面へ時間軸を重ねません。
共通アプリシェルの `mode=realworld` から表示し、選択、詳細表示、URL復元の基本操作だけを共有します。

## 基本レイアウト

- 横方向を過去から未来へ進む時間軸とします。
- 縦方向は `game`、`story`、`music`、`live`、`stream` のカテゴリレーンとします。
- MVPでは単一フィード表示との切替を設けません。
- 同じ `groupId` を持つ項目は、同一シリーズであることを詳細と補助表示で示します。
- 重なりはレーン内の段組みで避け、時刻や期間を変形して解消しません。

## 日時精度の表示

| 精度 | 表示 |
| --- | --- |
| `month` | 月全体に対応する帯と「YYYY年M月」 |
| `date` | その日を指すマーカーと「YYYY年M月D日」 |
| `minute` | 日時位置のマーカーとタイムゾーンを含む日時 |
| 開始と終了 | 精度に対応する期間帯 |

月精度の項目を月初の確定情報のように見せません。
期間端の包摂規則は[暦と時刻](calendar-semantics.md)に従います。

## 状態

- `scheduled` は「予定」ラベルと破線を併用します。
- `active` は「開催中」ラベルを表示します。
- `completed` は通常の履歴項目として表示します。
- `postponed` は「延期」ラベルと変更後の予定を表示します。
- `cancelled` は「中止」ラベルを表示し、項目自体は履歴から削除しません。

状態は色だけで伝えません。スクリーンリーダー用の名称にも状態を含めます。

## 表示範囲

初期表示範囲は、表示時点から過去12か月、未来90日とします。
公開済みの将来予定は同じビューに含めますが、この範囲を超える項目は「全期間を表示」で確認します。
既定範囲は承認後、実データ密度を使うMVP検証で再評価できます。

## 操作

- ホイール、ピンチ、キーボードでズームします。
- ドラッグ、タッチ、キーボードで時間軸をパンします。
- 「現在へ移動」と「全期間を表示」を提供します。
- 項目のクリック、タップ、EnterまたはSpaceで選択します。
- Escapeで詳細を閉じ、時間軸へフォーカスを戻します。
- 操作感は既存ビューの慣性、ズーム基準点、フォーカス規則を可能な範囲で再利用します。

## 検索と絞り込み

MVPの条件は次のとおりです。

- タイトルと概要の文字列検索。
- カテゴリ。
- 状態。
- 日付範囲。
- 関連キャラクター。
- 関連する物語イベント。
- 出典種別。

条件変更で選択中の項目が非表示になった場合は選択を解除し、URLから `item` を除きます。

## 詳細表示

詳細には、タイトル、概要、カテゴリ、状態、発表日時、開始、終了、タイムゾーン、関連項目、公式出典、訂正履歴を表示します。
存在しない日時を補完して表示しません。
関連する物語イベントがある場合は、そのノードを開く導線を置きます。

## URL

- ビューは `?mode=realworld` で表します。
- 選択は `?mode=realworld&item=<InfoEvent ID>` で表します。
- 存在しない、または公開されていないIDではビューだけを表示し、選択なしとします。
- 選択と解除はブラウザ履歴で戻れるようにします。
- ズーム位置や一時的なフィルターのURL保存はMVPの必須要件にしません。

## 狭い画面

- 時間軸自体を簡略版の別表示へ置換しません。
- レーン名と絞り込み操作を折り畳めるようにします。
- 詳細は下部シートまたは全幅パネルで表示します。
- タップ対象は既存UIの最小サイズ規則を満たします。
- 横パンとページの縦スクロールを競合させないことを実機相当のブラウザ検証で確認します。

## 空状態と障害時

- 公開済み項目がない場合は「公開済みの学マス情報史はまだありません」と表示します。
- 絞り込み結果がない場合は条件を解除する導線を表示します。
- 一部の出典URLへ到達できなくても項目は非表示にせず、保存済みの確認情報を表示します。

## 承認済みのMVP方針

- カテゴリレーンをMVPの唯一の表示形式とすること。
- 初期表示範囲を過去12か月から未来90日とすること。
- 将来予定を履歴と同じ画面へ表示すること。
- URLへ保存する状態を `mode` と `item` に限定すること。
