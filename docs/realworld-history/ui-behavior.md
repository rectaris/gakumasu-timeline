# 学マス情報史のUI挙動

- 状態：Draft
- 仕様バージョン：0.1

## 画面構成

共通シェル、暦目盛、レーン、情報項目、検索、詳細パネルの責務を定義します。

## レーンと項目

情報カテゴリのレーン構成、単日、期間、月単位、将来予定、延期、中止の表示規則を定義します。

## 操作

ズーム、パン、選択、キーボード移動、タッチ操作、現在位置への移動を定義します。

## 検索と表示条件

カテゴリ、期間、状態、関連キャラクター、関連StoryBlock、出典の検索と絞り込みを定義します。

## 詳細

発表日時、開催期間、状態、出典、関連項目、訂正履歴を表示する規則を定義します。

## URL

`mode=realworld`、`item` と将来の表示状態パラメータを定義します。

## レスポンシブ表示とアクセシビリティ

デスクトップ、狭い画面、フォーカス順、読み上げ、色以外の状態表現を定義します。

## 未決定事項

- 既定で表示する年月範囲。
- カテゴリレーンと単一フィード表示の切替要否。
- 将来予定を履歴と同じ画面へ表示する期間。
