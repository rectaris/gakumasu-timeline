# 学マス情報史 仕様承認チェックリスト

- 状態：Approved
- 対象仕様：Approved 0.2

この一覧は、実装計画066の基準として承認された項目です。

## 収録範囲

- [x] 初期カテゴリをゲームの主要開始・更新、ストーリー公開、楽曲公開、公式ライブ、公式配信の5種とする。
- [x] 定常的なSNS投稿、物販、個別キャンペーン、内容を変えない再開催、コミュニティ主催情報、軽微な運用告知を初期対象外とする。

## InfoEventの単位

- [x] 現実世界で一回発生する出来事を一つのInfoEventとする。
- [x] 告知日時と発生日時は同じInfoEventの別フィールドとし、告知だけを別項目にしない。
- [x] 複数公演など発生日時が異なるものは別InfoEventとし、`groupId` でまとめる。

## 暦と状態

- [x] 日時精度を `month`、`date`、`minute` の3種とし、不明な日や時刻を補完しない。
- [x] `minute` はIANAタイムゾーンを必須とし、既定は `Asia/Tokyo`、閲覧者のローカル時刻へ自動変換しない。
- [x] 状態を `scheduled`、`active`、`completed`、`postponed`、`cancelled` とする。
- [x] 延期、中止、訂正は現在値だけを上書きせず、出典付きの `revisions` に変更前後を残す。

## 出典と公開

- [x] 本番公開には、登録した日時と状態を裏付ける公式出典を必須とする。
- [x] 二次情報だけの項目は候補として `unreviewed` に置き、本番公開しない。
- [x] 削除または移動された公式URLは元URLと到達状態を残し、代替の公式URLを追加する。
- [x] 構造レビューと事実・出典レビューを分け、両方を通過した項目だけを公開する。

## UI

- [x] カテゴリレーンをMVPの表示形式とし、単一フィード切替は作らない。
- [x] 公開済みの将来予定を同じビューに表示し、「予定」を色以外でも示す。
- [x] 初期表示範囲を過去12か月から未来90日とし、全期間表示を別操作で提供する。
- [x] 選択URLを `?mode=realworld&item=<InfoEvent ID>` とし、一時的な表示位置やフィルターはMVPでURL保存しない。

## 他ビューとの境界

- [x] 物語イベントの公開情報を投影する場合、元データを正とし、手動InfoEventへ同じ事実を複製しない。
- [x] 学マス情報史から物語イベントを参照できるが、二つのビューを同じ時間軸へ重ねない。

## 運用と初期データ

- [x] 初期運用はリポジトリ内JSONの手動編集とし、管理画面や自動収集を作らない。
- [x] `scheduled` と `active` を予定日前後に再確認し、公開データ全体は四半期ごとに監査する。
- [x] 仕様承認後、各カテゴリの代表的な実在情報と公式出典を別レビューで確定する。

## 承認後の処理

1. 承認内容だけを `decisions/` のADRへ記録します。
2. 関連文書の状態を `Approved` へ変更します。
3. 開発計画066の仕様作業チェックを完了します。
4. 開発計画066を `active` へ移してMVP実装を開始します。
