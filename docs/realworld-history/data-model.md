# 学マス情報史のデータモデル

- 状態：Draft
- 仕様バージョン：0.1

## 対象

この文書は、現実世界の学マス関連情報を保存するデータと表示時の派生データを定義します。

## エンティティ

### InfoEvent

安定ID、カテゴリ、名称、発表日時、開始、終了、精度、タイムゾーン、状態、出典、関連エンティティの契約を定義します。

### InfoCategory

ゲーム、ストーリー、楽曲、ライブ、配信、メディアなどの分類と表示順を定義します。

### 関連エンティティ

StoryBlock、キャラクター、楽曲、イベント、公式発表との参照契約を定義します。

## ID

InfoEventの名前空間、一意性、公開後の互換性を定義します。
表示名や日付の変更だけではIDを変えない規則を定義します。

## 日時と状態

発表、公開、開始、終了、延期、中止、訂正、継続中、将来予定のフィールドを定義します。

## 保存データと派生データ

手動登録するInfoEventと、StoryBlockなどから生成する投影項目を区別します。

## 検証

一意性、日時形式、時系列順、精度、タイムゾーン、カテゴリ、出典、参照整合性、重複の検証条件を記載します。

## 未決定事項

- 発表と開催を1件のInfoEventにまとめる条件。
- 同じ企画の複数地域や複数公演を分ける単位。
- 訂正前情報を同一レコードへ履歴保存するか。
