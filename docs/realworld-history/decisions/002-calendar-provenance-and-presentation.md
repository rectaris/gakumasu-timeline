# 002 暦、出典、公開境界、表示

- 状態：Accepted
- 決定日：2026-07-29
- 対象仕様：学マス情報史 0.2

## 決定

- 日時精度は `month`、`date`、`minute` とし、不明な日や時刻を補完しません。
- 分精度ではIANAタイムゾーンを必須とし、既定を `Asia/Tokyo` とします。
- 訂正は出典付きの変更履歴を残します。
- 本番公開には、対象の事実を裏付ける公式出典と事実レビューを必須とします。
- 未レビュー候補と公開データを分け、本番生成物へ候補を含めません。
- 将来予定を同じビューへ表示し、カテゴリレーン、過去12か月から未来90日の初期範囲を使用します。
- 選択URLは `?mode=realworld&item=<InfoEvent ID>` とします。

## 理由

確認できた精度と過去の公式発表を失わず、誤った精度や無根拠の事実を本番へ出さないためです。
将来予定を履歴の延長として閲覧できる一方、状態は文字と線種でも区別します。

## 互換性への影響

精度、タイムゾーン、公開条件、既定表示範囲、選択URLの変更は、データ生成、検証、表示、共有URLへ影響します。
