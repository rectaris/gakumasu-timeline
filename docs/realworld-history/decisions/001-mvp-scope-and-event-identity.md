# 001 MVPの収録範囲とInfoEventの単位

- 状態：Accepted
- 決定日：2026-07-29
- 対象仕様：学マス情報史 0.2

## 決定

- MVPはゲームの主要開始・更新、ストーリー公開、楽曲公開、公式ライブ、公式配信を扱います。
- 定常SNS、物販、細かなキャンペーン、内容を変えない再開催、コミュニティ主催情報は対象外です。
- 現実世界で一回発生する出来事を一つのInfoEventとします。
- 告知と発生は同じInfoEventの別日時とし、別項目へ複製しません。
- 複数公演は別InfoEventとし、必要に応じて `groupId` でまとめます。

## 理由

歴史として意味のある出来事へ絞り、収集と保守を持続可能にします。
出来事と告知投稿を分けないことで重複を防ぎ、複数公演の個別日時は失いません。

## 互換性への影響

カテゴリ追加とInfoEventの統合・分割は、レーン、ID、公開URLへ影響するため仕様レビューを必要とします。
