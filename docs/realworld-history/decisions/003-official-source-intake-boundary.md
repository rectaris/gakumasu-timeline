# 003 公式ソースの取得境界

- 状態：Accepted
- 決定日：2026-07-29
- 対象仕様：学マス情報史 0.2

## 決定

- 承認済み公式発信元を`source-registry.json`へ登録します。
- 取得したページ、動画、投稿は、InfoEventにせず`intake/`の共通形式へ正規化します。
- 取得レスポンス全文は`.agent-artifacts/`へローカル保存し、コミットしません。
- Webサイト、YouTube Data API、X APIを取得方式とし、資格情報は環境変数だけから読みます。
- アイドルマスター全体の発信元では、学マスを明示する項目だけを候補にします。
- 収集処理は候補生成で停止し、InfoEventの作成、事実レビュー、公開を自動化しません。
- 複数の取得項目が同じ出来事を示す場合は、原則として1件のInfoEventの出典へまとめます。

## 理由

取得できたことと、歴史項目として採用できることを分離し、公式情報の見落としを減らしながら誤公開を防ぐためです。
また、資格情報と大きなレスポンスを公開データの保守境界から外します。

## 互換性への影響

`source-registry.json`と`intake/`は、本番表示データへ含めない前段の契約です。
取得元、判定語、正規化IDの変更は候補の継続性と重複判定へ影響するため、仕様レビューを必要とします。
