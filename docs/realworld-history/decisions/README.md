# 学マス情報史の決定記録

このディレクトリは、後から変更すると収録範囲、暦の意味、データ互換性が変わる承認済み判断を保存します。

現在の仕様バージョン0.2は `Proposed` です。
[承認チェックリスト](../review-checklist.md)の判断が完了するまでは、提案内容をADRとして確定しません。

## 保存対象

- 初期収録範囲と対象外情報。
- InfoEventの日時と状態の意味。
- 出典の優先順位と訂正方針。
- ID体系と公開URLの互換方針。
- StoryBlockなどからの投影境界。
- 大きなUI操作モデルの変更。

## 保存しない内容

- 検討中の選択肢一覧。
- 会話やレビューの全文。
- 個別項目だけに関係する判断。
- 日常的な情報追加の作業記録。

## ファイル形式

ファイル名は `NNN-short-slug.md` とします。
本文には状態、決定日、対象仕様、決定内容、短い理由、互換性への影響を記載します。
