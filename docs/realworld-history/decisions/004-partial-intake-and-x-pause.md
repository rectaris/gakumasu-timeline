# 004 部分取得とX取得の保留

- 状態：Accepted
- 決定日：2026-07-29
- 対象仕様：学マス情報史 0.2

## 決定

- ページ上限で打ち切った結果を`partial`として保存します。
- `partial`はページ数、上限、次ページの有無、今回の取得件数、以前の結果から保持した件数を記録します。
- `partial`は既存候補と`resourceKey`でマージし、今回取得しなかった候補を削除しません。
- 末尾まで確認した`collected`だけが既存候補全体を置き換えます。
- 発信元固有の失敗は後続ソースから隔離し、失敗した発信元の最後の有効なファイルを保持します。
- 学園アイドルマスター公式Xとアイドルマスター公式Xは`paused`とし、Xに対する通信を行いません。
- Xのログイン済みブラウザ、oEmbed、API取得は、保留解除の判断まで実装しません。

## 理由

ページ数を減らした再取得で候補が消えることを防ぎ、取得範囲をレビュー担当者が判別できるようにするためです。
外部サービスの失敗を他の公式ソースへ波及させず、X取得の費用と運用方法が未確定な期間は通信自体を停止します。

## 互換性への影響

既存の`collected`と`skipped`データセットは引き続き有効です。
新しい取得結果には`partial`と`pagination`が加わる場合がありますが、これらは本番表示データへ含めない取り込み境界の情報です。
