# 学マス情報史仕様

- 状態：Proposed
- 仕様バージョン：0.2
- 実装状態：実装前レビュー待ち
- 関連プラン：[066 Gakumasu Real-World History View](../plan/backlog/066-gakumasu-realworld-history-view.md)

## 目的

このディレクトリは、「学マス情報史」ビューの収録範囲、InfoEvent、現実世界の暦、出典、画面挙動、データ作成方法を管理します。

現在の文書は、実装前レビューに使用する提案仕様です。

状態をApprovedへ変更し、計画066をactiveへ昇格するまで、本番実装と実在データの登録を開始しません。

## 確定済みの前提

- 「学マス情報史」は現実世界史として扱います。
- グレゴリオ暦を使い、作中の31日固定月へ変換しません。
- 発表日時と、公開、開催、開始、終了の日時を区別します。
- 公式出典を基本とし、不明な日や時刻へ架空の精度を与えません。
- StoryBlockの公開情報は重複登録せず、必要に応じて投影します。
- 他の2ビューと同じ時間軸へ重ねません。
- 物語イベントの実データ登録より、学マス情報史の仕様策定を先に進めます。

## 提案するMVP範囲

初期版は、ゲームの開始と主要更新、ストーリー公開、楽曲公開、公式ライブ、公式配信を対象にします。

日常的な公式SNS投稿、物販、細かなキャンペーン、再開催、コミュニティイベントは初期対象に含めません。

公開項目には公式出典を必須とし、未レビュー候補と本番データを分離します。

## 実装開始条件

- [承認チェックリスト](review-checklist.md)の各項目が承認済みであること。
- 正式な決定を`decisions/`へ保存していること。
- 仕様状態をApprovedへ変更していること。
- 計画066の開始条件と受け入れ条件を承認済み仕様へ同期していること。
- 最初に登録する実在データと公式出典を別途レビューしていること。
