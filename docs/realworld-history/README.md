# 学マス情報史仕様

- 状態：Draft
- 仕様バージョン：0.1
- 実装状態：仕様策定前
- 関連プラン：[066 Gakumasu Real-World History View](../plan/backlog/066-gakumasu-realworld-history-view.md)

## 目的

このディレクトリは、「学マス情報史」ビューの現実世界データ、暦、出典方針、画面挙動、データ作成方法を長期参照できる仕様として管理します。

Draftの間は検討中の将来仕様であり、現在実装されている機能を示しません。
実装は仕様状態がApprovedになり、関連プランがactiveへ昇格した後に開始します。

## 文書構成

- [データモデル](data-model.md)：InfoEvent、カテゴリ、関連エンティティ、IDの契約を定義します。
- [暦意味論](calendar-semantics.md)：実日付、時刻、期間、精度、タイムゾーンを定義します。
- [出典方針](source-policy.md)：収録範囲、公式出典、訂正、削除済み情報を定義します。
- [UI挙動](ui-behavior.md)：暦表示、レーン、操作、検索、共有URLを定義します。
- [データ作成](authoring.md)：情報追加、出典確認、更新、訂正、検証を定義します。
- [例](examples.md)：代表的な現実世界の情報例を保存します。
- [決定記録](decisions/README.md)：長期的な影響がある承認済み判断を保存します。

## 確定済みの前提

- 「学マス情報史」は現実世界史として扱います。
- グレゴリオ暦を使い、作中の31日固定月へ変換しません。
- 発表日時と、公開、開催、開始、終了の日時を区別します。
- 公式出典を基本とし、不明な日や時刻へ架空の精度を与えません。
- StoryBlockの公開情報は重複登録せず、必要に応じて投影します。
- 他の2ビューと同じ時間軸へ重ねません。

## 仕様確定条件

- 初期収録範囲と対象外情報が確定していること。
- InfoEventと暦の契約が確定していること。
- 出典、訂正、延期、中止、将来予定の扱いが確定していること。
- 表示、操作、URL、検証、更新手順が定義されていること。
- 代表データによる仕様レビューが完了していること。

## 未決定事項

- 日常的なSNS投稿、物販、再開催を収録する基準。
- 将来予定と完了済み履歴の表示境界。
- 継続更新の担当とレビュー周期。
