# 物語時系列の決定記録

このディレクトリは、後から変更すると互換性や意味が変わる承認済み判断を保存します。

## 保存対象

- 時間表現と不確実性の意味。
- 公開IDと共有URLの互換方針。
- データのSource of Truth。
- 他ビューとの参照境界。
- 大きなUI操作モデルの変更。

## 保存しない内容

- 検討中の選択肢一覧。
- 会話やレビューの全文。
- 実装手順だけに関係する判断。
- Git履歴だけで十分に追跡できる軽微な変更。

## ファイル形式

ファイル名は `NNN-short-slug.md` とします。
本文には状態、決定日、対象仕様、決定内容、短い理由、互換性への影響を記載します。
