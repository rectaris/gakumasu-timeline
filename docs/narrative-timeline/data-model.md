# 物語時系列のデータモデル

- 状態：Draft
- 仕様バージョン：0.1

## 対象

この文書は、「物語時系列」に保存するドメインデータと表示時に生成する派生データの境界を定義します。

## エンティティ

### レーン

安定ID、表示名、配色、所有する出来事の契約を定義します。

### 出来事

安定ID、開始、終了、発生形式、説明、参加者、世界線、出典、不確実性の契約を定義します。

### 共通出来事

1件の正規データとレーンごとの表示インスタンスを区別する契約を定義します。

### 参照エンティティ

参加者、世界線、出典、将来のStoryBlock参照の解決規則を定義します。

## ID

- `canonicalId` の一意性と公開後の互換性を定義します。
- `instanceId` の生成と表示用途を定義します。
- 他ビューのID名前空間との衝突回避を定義します。

## 出典と不確実性

`source`、構造化出典、出典状態、日付確度、矛盾情報の役割を定義します。
StoryBlockを出典として参照する場合の多対多関係は、物語イベント仕様と整合させます。

## 保存データと派生データ

rawデータ、生成物、表示正規化値の責務を定義します。
生成可能な値を重複保存しないための基準も定義します。

## 検証

ID、日付範囲、enum、参照整合性、出典、不確実性の検証条件を記載します。

## 未決定事項

- StoryBlockへの参照フィールドをどのエンティティが所有するか。
- レーン種別を現行カテゴリから独立した契約にするか。
- 現行互換フィールドを廃止可能と判断する条件。
