# 物語時系列のUI挙動

- 状態：Draft
- 仕様バージョン：0.1

## 画面構成

ヘッダー、メニュー、レーンラベル、時間目盛、描画領域、詳細パネルの責務を定義します。

## 描画

通常の出来事、共通出来事、不確定期間、密集サマリー、選択状態の表示規則を定義します。

## 操作

ホイール、ドラッグ、タッチ、キーボード、ズーム、レーン密度の挙動を定義します。

## 選択と詳細

出来事選択、パネル表示、関連コンテキスト、フォーカス移動、閉じる操作を定義します。

## 検索と表示条件

検索対象、フィルタ、レーン表示、集中表示、比較表示、条件解除を定義します。

## URL

`event`、既存の `view=1` 表示状態、`mode=narrative` との互換規則を定義します。

## レスポンシブ表示とアクセシビリティ

デスクトップ、狭い画面、フォーカス順、読み上げ名、色以外の状態表現を定義します。

## 回帰条件

現在の操作感から変更してはならない挙動と、変更時に必要なブラウザ確認を記載します。
