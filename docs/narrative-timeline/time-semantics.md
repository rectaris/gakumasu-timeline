# 物語時系列の時間意味論

- 状態：Draft
- 仕様バージョン：0.1

## 時間軸

学園の1年目を基準とする相対年と、1か月を31日として扱う抽象時系列の契約を定義します。

## 時点と期間

開始、終了、日付省略、月全体、複数年範囲の意味を定義します。
保存上の範囲と画面上の表示範囲を区別します。

## 発生形式

継続期間と、期間内のいずれか1日に発生する出来事を区別します。
発生形式を表示上の形だけで判断しないための規則を定義します。

## 不確実性

確定、推定、範囲のみ、出典矛盾の意味と表示要件を定義します。
不明な時点を中央値や便宜上の日付へ変換しない規則を定義します。

## 順序

同一日、重複期間、相対順序だけが判明している出来事の並べ方を定義します。

## 他ビューとの関係

StoryBlockの本編発生時期と、StoryBlockが根拠として示す過去の出来事の時期を区別します。
現実世界の日付はこの時間軸へ変換しません。

## 未決定事項

- 相対順序しか判明しない出来事を将来どのように保存するか。
- 時期未確定の出来事を表示領域へ置くか、検索対象だけにするか。
- 3ビュー共通の時間座標インターフェースをどこまで定義するか。
