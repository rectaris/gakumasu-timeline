# 物語時系列仕様

- 状態：Draft
- 仕様バージョン：0.1
- 実装状態：既存実装を仕様化している段階
- 関連プラン：[064 Three-View Application Shell](../plan/backlog/064-three-view-application-shell.md)

## 目的

このディレクトリは、「物語時系列」ビューのデータ意味、時間表現、画面挙動、データ作成方法を長期参照できる仕様として管理します。

Draftの間は、既存の実装、[データ構造](../data-structure.md)、[UI挙動](../ui-behavior.md)を現在動作の正とします。
この仕様がApprovedになった後、実装との差異を解消して現在仕様の参照先を切り替えます。

## 文書構成

- [データモデル](data-model.md)：レーン、出来事、参加者、世界線、出典、IDの契約を定義します。
- [時間意味論](time-semantics.md)：抽象時系列、期間、不確実性、表示位置を定義します。
- [UI挙動](ui-behavior.md)：レーン表示、操作、選択、検索、共有URLを定義します。
- [データ作成](authoring.md)：rawデータの作成、出典記録、検証、生成手順を定義します。
- [例](examples.md)：仕様を検証する代表例を保存します。
- [決定記録](decisions/README.md)：長期的な影響がある承認済み判断を保存します。

## 確定済みの前提

- 「物語時系列」は他の2ビューと同じ時間軸へ重ねません。
- 時間軸は学園の1年目を基準とする作中の抽象時系列です。
- 不明な時期へ架空の確定日を与えません。
- 公開済みの `canonicalId` と共有URLの互換性を維持します。

## 仕様確定条件

- 既存実装と既存文書から現行契約を抽出していること。
- データ、時間、UI、データ作成の各仕様に矛盾がないこと。
- 回帰確認の対象と受け入れ条件が明文化されていること。
- 未決定事項が解消され、仕様状態がApprovedへ更新されていること。

## 未決定事項

- 現行実装から仕様として固定する範囲を整理します。
- 3ビュー共通シェルへ移す状態と、物語時系列固有の状態を整理します。
- 「物語イベント」のStoryBlockとの参照契約を整理します。
