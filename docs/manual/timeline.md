# タイムライン操作マニュアル

このマニュアルは、本番タイムライン画面の項目説明と操作方法をまとめたものです。
アプリ内の簡易マニュアルよりも、各項目の意味を確認しやすい保守用の参照資料として扱います。

## 対象画面

- 通常表示: `/timeline/`
- 開発サーバーでの通常表示: `http://127.0.0.1:<port>/timeline/`

Worldline Data Editor は `/timeline/?editor=worldline` の開発用画面です。編集画面の操作は [Worldline Data Editor マニュアル](./worldline-data-editor.md) を参照してください。

## 画面構成

| 項目 | 説明 |
| --- | --- |
| 固定ヘッダー | 画面上部に固定される操作領域です。メニュー、マニュアル、設定を開けます。 |
| 初見向け案内カード | 初回利用時に基本操作を案内します。閉じるとブラウザに状態が保存されます。 |
| 左メニュー | カテゴリ、レーン、検索、絞り込み、比較表示を操作します。 |
| 表示条件バー | 検索、絞り込み、表示範囲、比較表示などが有効な時に現在条件を表示します。 |
| 設定メニュー | 配色モード、共通イベント表示、操作ヒント表示を切り替えます。 |
| タイムライン本体 | レーンごとのイベントを抽象時系列上に表示します。 |
| ズーム操作エリア | 表示期間、全体期間バー、プリセット、レーン密度を操作します。 |
| 詳細パネル | 選択中イベントの詳細を表示します。デスクトップでは右側、モバイル幅では下部に開きます。 |
| 広告エリア | タイムライン内容の末尾に配置されます。 |

## ヘッダー

| 項目 | 説明 | 操作 |
| --- | --- | --- |
| メニュー | 左メニューを開きます。 | ヘッダー左のメニューボタンを押します。 |
| マニュアル | アプリ内マニュアルを開きます。 | ヘッダー左のマニュアルボタンを押します。 |
| 設定 | 表示設定を開きます。 | ヘッダー左の設定ボタンを押します。 |
| タイトル | 現在のアプリ名を表示します。 | 操作対象ではありません。 |

## 左メニュー

### カテゴリ

表示するコミュ種別を選びます。

| カテゴリ | 説明 |
| --- | --- |
| アイドルコミュ | アイドルごとのコミュイベントです。 |
| 初星コミュ | 初星学園関連のコミュイベントです。 |
| イベントコミュ | イベントコミュの時系列です。 |
| サポートカードコミュ | サポートカードコミュの時系列です。 |

カテゴリを切り替えると、レーン一覧、検索候補、表示対象イベントが切り替わります。

### レーン検索

レーン名を入力して、左メニュー内のレーン一覧を絞り込みます。
タイムライン上のイベント検索とは別の入力です。

### 並び替え

レーン一覧とタイムライン上の表示順を切り替えます。
既定順、イベント数順など、現在の実装で用意された選択肢が表示されます。

### 表示レーン

チェックしたレーンだけがタイムラインに表示されます。
初期状態では、選択中カテゴリのレーンがすべて表示されます。

| 操作 | 説明 |
| --- | --- |
| レーンのチェック | 対象レーンの表示/非表示を切り替えます。 |
| 表示中を一括 | レーン検索で表示中のレーンだけをまとめて選択/解除します。 |
| 比較 | 2〜4件のレーンを一時的に比較表示へ追加します。 |

表示レーンをすべて外しても、横方向の表示位置と拡大率は保持されます。

## イベント検索と絞り込み

イベント検索は、現在のカテゴリと表示レーン内のイベントを対象にします。
比較表示中は、比較対象レーン内だけを検索します。

| 項目 | 説明 |
| --- | --- |
| 検索語 | タイトル、詳細、出典、注記、レーン名、参加者、世界線などを検索します。スペース区切りは AND 条件です。 |
| 発生形式 | 継続期間か、候補範囲内の1日イベントかで絞り込みます。 |
| 日付確度 | 確定、推定、期間内の1日、出典矛盾などの派生状態で絞り込みます。 |
| 監査カテゴリ | 出典矛盾、出典なし、未確認、分類不能、推定、期間内の1日で絞り込みます。 |
| 出典 | `sourceDetails` または `source` から作られた出典キーで絞り込みます。 |
| 参加者 | イベントに紐づく参加者で絞り込みます。 |
| コミュ | レーン/コミュ名で絞り込みます。 |
| 世界線 | `worldlineId` の表示名で絞り込みます。 |
| 前へ / 次へ | 現在の検索・絞り込み結果を時系列順に移動します。 |

共通イベントは複数レーンに表示されますが、検索結果件数と前後移動では canonical ID 単位にまとめます。

## 表示条件バー

検索、絞り込み、表示レーン、比較表示、表示範囲などが有効な場合、タイムライン上部に現在条件が表示されます。

| 項目 | 説明 |
| --- | --- |
| 条件チップ | 有効な検索語、フィルタ、表示状態を示します。 |
| 表示URL | 現在の表示状態を復元できる URL をコピーします。 |
| 解除 | 選択中イベントを残したまま、検索・絞り込みなどの表示条件を初期状態へ戻します。 |

## タイムライン本体

| 表示 | 説明 |
| --- | --- |
| レーン | コミュまたはアイドルなどの単位です。左側にラベルが表示されます。 |
| イベントバー | イベントの開始から終了までの範囲を表示します。 |
| 丸マーカー | イベントの開始点と終了点を示します。 |
| 破線バー | `singleWithinRange` の候補範囲内の1日イベントを示します。 |
| 不確定マーカー | 具体日が確定していない範囲イベントの両端に表示されます。 |
| 共通イベント | 共通イベント専用の中立色と菱形インジケータで表示されます。 |
| 密集イベントマーカー | ズームアウト時に近接イベントを件数でまとめた表示です。 |
| イベント名ラベル | バー幅と高さに余裕がある場合だけ表示されます。 |
| ツールチップ | イベントへマウスオーバーまたはフォーカスすると、タイトル、詳細、コミュ、時期、発生形式、日付確度、根拠分類、出典状態、範囲理由を表示します。 |

イベントバーをクリックすると、詳細パネルが開きます。
タイムライン上の空き領域をクリックすると、詳細パネルを閉じます。

## 詳細パネル

詳細パネルは、選択中イベントの内容と関連情報を確認する領域です。
項目名とセクション見出しにマウスオーバーまたはキーボードフォーカスすると、項目説明が表示されます。

| 項目 | 説明 |
| --- | --- |
| タイトル | イベント名です。 |
| このレーンに集中 | 選択中イベントのレーンだけを一時表示します。 |
| 比較に追加 | 選択中イベントのレーンを比較対象に追加します。 |
| URLをコピー | 選択中イベントを復元できる共有 URL をコピーします。 |
| レーン | イベントが属するコミュまたは共通イベントの表示レーンです。 |
| 期間 | イベントが起きた時期です。候補範囲内の1日は「いずれか1日」として表示されます。 |
| 発生形式 | 継続期間か、候補範囲内の単日イベントかを示します。 |
| 日付確度 | 日付が確定か推定か、または範囲だけ特定されているかを示します。 |
| 根拠 | 時期や内容の判断根拠が、明示情報・推論・混在のどれかを示します。 |
| 出典状態 | 出典の確認状態、推定根拠、矛盾、未確認、出典なしなどを示します。 |
| 範囲理由 | 候補範囲になっている理由です。 |
| 世界線 | イベントに紐づく世界線です。未設定の場合は「未設定」と表示されます。 |
| 参加者 | イベントに関係する登場人物です。 |
| 出典 | 簡易出典です。クリックすると同じ出典で絞り込めます。 |
| 出典詳細 | 構造化された出典情報です。ID、状態、対象、主張を確認できます。 |
| 出典矛盾 | 複数の出典や解釈が食い違う場合の矛盾内容です。 |
| 詳細 | イベント本文です。 |
| 注記 | 判断理由、保留事項、補足情報などです。 |
| 関連コンテキスト | 同時期、同じレーン、同じ出典、同じ参加者などの関連イベントです。因果関係を示すものではありません。 |

選択中イベントが検索・絞り込み・比較表示などで非表示になっても、詳細パネルは閉じず、現在条件では非表示であることを表示します。

## ズームと移動

### 表示期間

| 操作 | 説明 |
| --- | --- |
| 表示期間 `-` | 水平ズームアウトします。 |
| 表示期間 `全体` | 全イベントが入る表示幅へ戻します。 |
| 表示期間 `+` | 水平ズームインします。 |
| 全体期間バー | 全体期間内の現在位置を示します。クリックした位置を中心へ移動できます。 |
| 選択イベントマーカー | イベント選択中に、全体期間バー上へ選択イベントの位置を表示します。 |
| `年` | 12か月分を表示します。 |
| `月` | 1か月分を表示します。 |
| `詳細` | 7日分を表示します。 |
| `戻る` | 選択中イベントが見える位置へ戻ります。 |

### レーン密度

| 操作 | 説明 |
| --- | --- |
| 密度 `-` | レーン密度を下げ、縦方向を広めに表示します。 |
| 密度 `100%` | レーン密度を初期値へ戻します。 |
| 密度 `+` | レーン密度を上げ、縦方向を詰めて表示します。 |

レーン密度を変えても、イベントバー、選択アウトライン、フォーカス表示、不確定表示の縦サイズは変わりません。

### マウス/タッチ

| 操作 | 説明 |
| --- | --- |
| ホイール | カーソル位置を基準に表示期間を拡大/縮小します。 |
| Ctrl + ホイール | レーン密度を調整します。 |
| 横方向ホイール | 水平方向へ移動します。 |
| ドラッグ | タイムライン領域を上下左右へ移動します。 |
| 1本指ドラッグ | タッチ環境で上下左右へ移動します。 |
| 2本指ピンチ | 表示期間とレーン密度を同時に調整します。 |

## キーボード操作

| キー | 説明 |
| --- | --- |
| `/` | メニューを開き、イベント検索欄へ移動します。 |
| `N` | 現在の検索・絞り込み結果の次のイベントへ移動します。 |
| `P` | 現在の検索・絞り込み結果の前のイベントへ移動します。 |
| `R` | 選択中イベントへ戻ります。 |
| `←` / `→` | 表示範囲を左右へ移動します。 |
| `+` / `-` | 表示期間を拡大/縮小します。 |
| `Enter` / `Space` | フォーカス中のイベントや密集イベントを選択します。 |
| `Escape` | マニュアル、設定、メニュー、詳細パネルの順で開いている面を閉じます。 |

## 設定

| 項目 | 説明 |
| --- | --- |
| システム設定に合わせる | OS / ブラウザの配色設定へ追従します。 |
| ホワイトモード | 明るい配色で表示します。 |
| ダークモード | 暗い配色で表示します。 |
| 共通イベントを表示する | 共通イベントの表示/非表示を切り替えます。 |
| 操作ヒントを表示する | ズーム操作エリアの補足ヒントを表示/非表示にします。 |

## URL共有

| URL要素 | 説明 |
| --- | --- |
| `event=<eventId>` | 選択中イベントを復元します。 |
| `view=1` | 表示状態の復元パラメータが含まれていることを示します。 |
| `cat` | 選択カテゴリを復元します。 |
| `lanes` / `lm` | 表示レーン状態を復元します。 |
| `focus` | レーン集中表示を復元します。 |
| `compare` | レーン比較表示を復元します。 |
| `range` | 水平表示範囲を復元します。 |
| `scale` | レーン密度を復元します。 |
| `common` | 表示条件バーから共有した場合に、共通イベント表示状態を復元します。 |

配色、操作ヒント、初見向け案内カードの状態は個人設定として扱い、通常の共有 URL には含めません。

## 日付表示の前提

- 実カレンダーではなく、各月31日換算の抽象時系列です。
- `1年目`、`2年目`、`n年前` のような相対的な年表示を使います。
- 月ラベルと日付ラベルは、画面上で十分な間隔がある場合だけ表示されます。
- `singleWithinRange` は候補期間を示し、中央日付や確定日を意味しません。

## 困った時

| 状態 | 対応 |
| --- | --- |
| 目的のイベントが見つからない | カテゴリ、表示レーン、検索語、絞り込み条件を確認します。 |
| 選択中イベントが見えない | 詳細パネルの `戻る` 操作、またはズーム操作エリアの `戻る` を使います。 |
| 表示条件が複雑になった | 表示条件バーの `解除` で初期状態に戻します。 |
| 共有先で同じ表示にならない | 詳細パネルの `URLをコピー` はイベント選択用、表示条件バーの `表示URL` は表示状態込みです。用途に応じて使い分けます。 |
